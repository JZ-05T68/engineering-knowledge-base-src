# Engineering Knowledge Base v0.2.2 发布说明

发布日期：2026-07-26

## 版本定位

v0.2.2 是扫描页与缺失文本层页面的**本地 OCR 补充**版本。它为没有可靠 PDF 文本层的页面
提供按需、单页、完全离线的文字识别，让扫描资料也能进入既有全文搜索与证据工作流。
本版本不是 AI 文档理解、智能解析或多模态识别版本；Windows 本地、单用户、离线优先的
产品定位不变。

## 主要能力

- 待整理页面提供“执行本地 OCR”按钮：一次只处理当前页，用户显式点击才执行，不自动识别。
- OCR 引擎为 RapidOCR + ONNX Runtime，识别模型随安装包提供，完全本地离线运行。
- 引擎延迟加载：应用启动和普通浏览不加载模型，只有第一次执行 OCR 时才初始化。
- OCR 结果写入独立的 `ocr_text` 字段，作为“OCR 初稿”只读展示，并明确标注未经人工核验、
  以原始页面图像为准；不会写入或覆盖人工 Markdown。
- 搜索既有 FTS 同时检索 OCR 文本，命中字段会标注来源为 OCR。
- OCR 文本加入证据篮后，导出的证据包固定显示“本地 OCR 初稿、未经人工核验、以原始页面
  图像为准”警告。
- 原始 PDF、页面 PNG、`extracted_text`（PDF 文本层）、人工 Markdown 和复核状态都不会被
  OCR 修改；OCR 不会把页面自动标记为已复核。
- 单页失败隔离：识别失败只在该页记录脱敏错误，其他页面和既有功能不受影响。
- 本地 OCR 引擎缺失或初始化失败时，仅 OCR 按钮提示不可用，导入、搜索、证据等核心功能
  继续可用。

## OCR 来源语义

- `extracted_text` = PDF 自带文本层；`ocr_text` = 本地 OCR 初稿；`markdown_content` = 人工稿。
- 显示与搜索优先级保持为：人工 Markdown > OCR 初稿 > PDF 文本层。
- 只有文本层不足且页面图像可用的页面才符合 OCR 条件；已有可靠文本层的页面不执行 OCR。
- 已有有效 OCR 结果的页面不显示执行按钮，不默认重复识别。

## 安全与数据边界

- 无云端 OCR、无 API Key、无运行时模型下载、无任何网络访问。
- 不覆盖原始 PDF、页面图像、PDF 文本层或人工 Markdown。
- 不自动修改 `review_status`；一次只处理当前页，不提供批量 OCR。
- OCR 相关错误在持久化和界面展示前统一脱敏，不包含本机路径或 traceback。

## 依赖

- 新增依赖范围：`rapidocr>=3.9.2,<4`、`onnxruntime>=1.27.0,<2`。
- 本版本发布验证组合：rapidocr 3.9.2、onnxruntime 1.27.0、Python 3.11.9。
- 以上范围内的其他未来版本未逐一验证，不代表已经测试。
- 数据库 schema 保持 v4，无迁移。

## 首次加载说明

- 第一次执行 OCR 需要加载本地模型，首次操作会比后续操作慢。
- 隔离测试环境测得首次识别（含模型初始化）约 2.53 秒；该数字仅为测试环境结果，
  不构成性能承诺。

## 验证情况

- Ruff 全量检查通过。
- 自动化测试 456 项全部通过，包括 RapidOCR 适配器单元测试、真实离线 OCR 识别测试、
  OCR 搜索与证据闭环测试和单页 OCR 界面测试。
- 隔离人工测试 MT-01～MT-10 全部通过，详见 `docs/v0.2.2-manual-test-results.md`：
  英文与中文扫描页均正确识别，OCR 进入搜索与证据警告，数据保护与重复执行保护有效。
- 人工验证全程未触碰正式数据库与正式工作区，正式服务 8501 未受影响。

## 已知限制

- 仅适合印刷体文字；手写、公式、复杂表格结构识别不在本版范围。
- 不提供批量 OCR、后台 OCR、自动 OCR 或强制重新 OCR。
- 不包含图像自动旋转、裁边或图像增强；这些能力延期，不在本版范围。
- OCR 初稿未经人工核验，可能含错字、漏字或顺序错误，引用前必须以原始页面图像为准。
- 具有可靠 PDF 文本层的页面默认不执行 OCR。

## 升级说明

- 停止旧版本服务，替换为 v0.2.2 程序并按 `requirements.txt` 安装依赖后正常启动即可；
  无需数据迁移。
- 首次启动后可在“系统维护”页确认应用版本显示为 v0.2.2，schema 仍为 v4。
