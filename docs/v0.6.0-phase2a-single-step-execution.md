## Scope

建立 Single-step read-only Agent execution kernel：

```text
Agent Request
    ↓
ONE structured decision
    ↓
0 or 1 READ_ONLY Tool execution
    ↓
structured observation/result
    ↓
STOP
```

本阶段不接真实模型、不做 Final Answer Stage、不做 multi-step、不做 schema v13、不做 UI。

## Frozen Preconditions

- Phase 1 seven-tool registry 精确冻结；
- READ_ONLY only；
- max tool calls per run = 1；
- Agent autonomous retry = 0；
- Adapter retry = 0；
- transport retry 仍遵循既有 ≤2 规则（本阶段无 transport）；
- RAG Answer = Final Answer Stage，不是 Tool；
- schema v13 deferred；
- no third-party Agent framework。

## Execution Flow

```text
SingleStepAgentExecutor.execute(request, provider)
  → provider.decide(request) exactly once
  → validate AgentDecision
  → ANSWER_DIRECTLY? → completed, 0 tool calls, STOP
  → ToolRegistry.resolve(tool_name)   # Phase1ReadOnlyPolicy applied here
  → handler(tool_input, tool_context) exactly once
  → capture ToolResult
  → structured AgentExecutionResult, STOP
```

## Decision Contract

- `AgentDecisionKind`：`CALL_TOOL` / `ANSWER_DIRECTLY`（ADR-006 的 NO_TOOL 语义）。
- `AgentDecision`：frozen dataclass；`CALL_TOOL` 必须且只能有一个 `tool_name` 和一个 `arguments` mapping；`ANSWER_DIRECTLY` 不允许携带 Tool 信息。
- 类型层不存在 `tool_calls` 列表字段；未知构造字段（如 `run_shell`）直接 `TypeError` fail closed。
- `DecisionProvider` Protocol：只表达“给出一个已结构化 AgentDecision”，不是第二套 AI Provider。

## Tool Execution Boundary

- Executor 只通过 `ToolRegistry.resolve()` 找 Tool，绝不 import 具体 service。
- Handler 必须由调用方注入（`handlers: Mapping[str, ToolHandler]`）。
- ToolInput 继续使用 Phase 1A 冻结的 `ToolInput` envelope。
- Phase1ReadOnlyPolicy 复用：WRITE Tool 在 resolve 阶段被拒绝，handler 不会被调用。

## Failure Semantics

| 情形 | 行为 |
|---|---|
| Decision Provider raise | FAILED，tool_call_count=0，retry=0 |
| 非 AgentDecision 返回值 | INVALID_DECISION |
| 未知 Tool | UNKNOWN_TOOL，handler 0 次调用 |
| WRITE Tool | TOOL_NOT_ALLOWED，handler 0 次调用 |
| Handler 意外 raise | TOOL_EXECUTION_FAILED，handler 1 次调用，无 retry |
| Tool FAILED（含 retryable=true） | 保留 ToolResult，execution FAILED，retry=0 |
| Tool EMPTY / PARTIAL / SUCCESS | execution COMPLETED，保留 ToolResult，STOP |

所有错误 message 为 safe message；detail 只保留异常类型名，不暴露 stack/path/secret/private content。

## Runtime Trace

- `AgentRuntimeTrace` 是 in-memory frozen dataclass。
- 记录：run_id、request_id、started_at、duration_ms、decision_kind、selected_tool、decision_call_count、tool_call_count、retry_count、tool_status、outcome、error_code、error_message。
- 不保存用户请求全文、API key、stack trace、完整 ToolResult 大对象副本。
- 不写数据库、不写 trace 文件、不写 JSON 日志 artifact。

## Safety Invariants

- decision_call_count ≤ 1；
- tool_call_count ≤ 1；
- retry_count = 0；
- loop = 0；
- multi-step = 0；
- write tool executable = NO；
- unknown tool fuzzy resolution = NO；
- multiple tool request = type-level fail closed。

## Mock-first Evidence

- `tests/test_agent_execution.py`（27 tests）覆盖：NO_TOOL、valid CALL_TOOL、unknown tool、WRITE tool、invalid arguments、EMPTY/PARTIAL/FAILED+retryable、Decision Provider failure、handler exception、multiple-tool/extra-field attack、determinism、runtime trace、in-memory-only trace、production registry integration、UI/provider independence。
- 全部使用 FakeDecisionProvider / FakeToolHandler / tmp DB，不调用真实模型。

## Real API Evidence

- execution 模块不 import `src.ai.provider` / `src.ai.qwen_client` / `urllib.request` / Streamlit。
- Real completion / embedding / rerank calls = 0。

## Non-goals

- 不实现 Final Answer Stage / RAG Answer。
- 不实现 conversation memory / planning / multi-step。
- 不修改 Tool Contract（Tool Contract changed = NO）。

- 不新增 dependency。
