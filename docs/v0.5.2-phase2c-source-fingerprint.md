## 状态机（实际契约）

| 输入状态 | 操作 | 新状态 | version | captured_at | side effect |
|---|---|---|---|---|---|
| 新链接（目标可计算） | link_source / create(source_links) | VALID | 1 | 现在 | 来源行 + source_linked revision（同事务） |
| 页面无文本层 | link_source | 拒绝 | — | — | 无写入（整体回滚） |
| 目标缺失 | link_source | 拒绝 | — | — | 无写入 |
| 存储指纹 NULL（legacy） | source_views（读） | UNKNOWN | 1 | 迁移时点 | 无 |
| 当前指纹 == 存储指纹 | source_views（读） | VALID | 1 | 不变 | 无 |
| 当前指纹 != 存储指纹 | source_views（读） | CHANGED | 1 | 不变 | 无 |
| 目标不存在 | source_views（读） | MISSING | 1 | 不变 | 无 |
| 同指纹重采 | recapture_source_fingerprint | 原状态 | 1 | 不变 | 无写入 |
| 指纹变化重采 | recapture_source_fingerprint | VALID | 1（配方版本不变） | 现在 | 覆盖 fingerprint + captured_at，无 revision |
| legacy NULL 重采 | recapture_source_fingerprint | VALID 或 CHANGED | 1 | 现在 | 同上 |
| 重采目标缺失 | recapture_source_fingerprint | 拒绝 | — | — | 无写入 |

对象级聚合：`aggregate_source_state(valid, changed, missing, unknown)` 六规则；
`evidence_sufficient` 要求聚合 VALID 且所有 evidence 来源 confirmed。

## 已知限制

- legacy NULL 来源不自动回填，由用户通过 recapture 逐条转为 VALID/CHANGED
  （Phase 2B 已按 NULL 回填，schema 不再新增 migration）。
- 页面失去文本层在读路径表现为 MISSING（不可计算），契约未规定该边界，按最保守
  解释处理。
- 聚合状态暂未接入 prompt builder / 全局 UI（留待 Phase 5 UI 收口）。
