# EKB v0.5.0 — AI Foundation / Optional Hybrid Retrieval

- 发布日期：2026-08-17
- runtime closure baseline：`664d5ef03ee2d1944ebfe993430c4b18aa41805b`
- 正式 tag：`v0.5.0`（指向最终 GitHub release presentation commit）

## Summary

EKB v0.5.0 是第一个正式引入 AI provider 基础设施与 Hybrid Retrieval 的公开版本。
它继续以本地文件和 SQLite 为唯一事实来源：PDF 导入、关键词检索、阅读、笔记、证据、
删除恢复和备份都不依赖云端 AI。可选 AI 只在用户显式配置和操作时介入。

## Highlights

- Qwen provider foundation：Completion / Embedding / Rerank 职责分离的厂商无关契约；
- 受控 Qwen 真实调用：主 LLM 默认 `qwen3.7-plus`，thinking 显式关闭；
- page-level embedding：`qwen3.7-text-embedding`，1024 维，本地 SQLite 持久化；
- SHA-256 freshness：来源文本未变化时复用已有向量；
- persistent vector recall 与本地 lexical recall 候选并集；
- RRF Hybrid Retrieval、来源标签、产品门控与关键词 fallback；
- page indexing orchestration、批量限制、staging guard 与 cost guard；
- production / staging 数据、端口、日志、备份与 PID 完全隔离；
- Phase 10C/10D/10E、Phase 11C/11D 的真实 retrieval 与 benchmark 证据。

## AI Stack 与当前边界

| 职责 | 默认配置 | v0.5.0 状态 |
|---|---|---|
| 主 LLM | `qwen3.7-plus` | provider foundation 与受控真实调用 |
| 高难度模型配置 | `qwen3.8-max` | 保留配置位；不承诺自动路由 |
| Embedding | `qwen3.7-text-embedding` | page-level 持久索引与 query embedding |
| Rerank | `qwen3-rerank` | 契约和配置已预留；运行时通道未接入 |

AI 默认 `ai_mode="manual"`。未配置 API Key 时，默认传输层拒绝网络调用，全部离线功能继续工作。

## Hybrid Retrieval

1. `SearchService` 执行自然语言词面召回；
2. SQLite 中已有且 fresh 的 page-level embedding 执行 persistent vector recall；
3. lexical 与 vector 候选取并集并使用 RRF 融合；
4. UI 显示关键词、语义或混合来源标签；
5. 存在筛选或非相关度排序时回退到关键词检索。

一次显式“搜索 / 应用筛选”至多调用一次 query embedding；URL/deep-link 恢复不自动调用。
当前没有 chunk-level indexing，也不把 retrieval 描述为已经完全解决或能够取代 keyword search。

## Safety / Architecture

- local-first、Windows、本地单用户；无注册、登录、OAuth、JWT、权限系统或云同步；
- production：`127.0.0.1:8501` + `data/`；
- staging：`127.0.0.1:8502` + `staging-data/`；
- 原始 PDF 与页面 PNG 不自动覆盖或删除；
- production 不自动生成 embedding；真实付费索引只允许在隔离 staging 流程显式执行；
- application runtime 正式策略 `max_extra_attempts = 0`，无递归重试或 Agent 循环；
- Prompt Package 在本地生成，仅接纳 confirmed evidence，并在来源失效时 fail closed。

## Known Limitations

- 当前索引粒度是 page-level，不是 chunk-level；
- `qwen3-rerank` 通道尚未接入；
- 真实付费能力需要显式 API 配置，离线模式不会获得语义向量增量；
- 最小 benchmark 只有 5 条 frozen query，需要持续扩展真人问题集；
- Hybrid 仍可能误召回，AI 不能替代来源核验、人工判断或关键词检索；
- v0.5.0 发布不表示 v0.6.0 已开始。
