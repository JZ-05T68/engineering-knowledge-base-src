## 一、本版本定位

v0.5.0 是 EKB 首个正式 AI 接入版本，在**不破坏任何离线能力**的前提下，加入了
可选的 AI 能力层（默认手动模式 `ai_mode = "manual"`）。核心原则：

- AI 是**可选增强，绝不作为启动依赖**：未配置 API Key 时应用照常启动，全部原有
  离线功能（PDF 导入、全文检索、阅读、笔记、证据、删除/恢复、备份）行为不变。
- 官方运行时 AI 供应商为 Qwen（阿里云百炼 / DashScope）。业务服务只依赖
  `src/ai/provider.py` 的厂商无关契约；厂商细节仅存在于 `src/ai/qwen_client.py`。
- API Key 不落库、不进日志/诊断/备份/测试快照，经 `EKB_AI_API_KEY` / `.env`
  读入 `SecretStr`。

## 二、新增能力

### AI 混合检索（Hybrid Search）

- 关键词检索（默认）之外，新增「AI 混合检索」模式。
- 混合检索 = 自然语言词面检索（`SearchService`）+ 语义向量召回
  （`qwen3.7-text-embedding`，1024 维，config_version=1）经 RRF 融合。
- 产品门控（`src/search_mode.py`）：仅当「无任何筛选 + 按相关度排序」时才启用
  hybrid；任何筛选或非相关度排序静默退回关键词检索。
- 结果带粗粒度来源标签（关键词匹配 / 语义召回 / 混合匹配），不暴露原始分数。
- 一次显式「搜索 / 应用筛选」触发**至多一次** query embedding；URL/deep-link 恢复
  不自动触发付费调用，必须显式点击。

### 页面向量索引（可选付费能力）

- 页面 embedding 持久化于 SQLite `page_embeddings`，带 freshness 指纹
  （`source_text_sha256`），缺失/过期才按需生成，成本有界。
- 仅在隔离 staging 实例（端口 8502，`staging-data/`）下启用真实付费索引；
  正式 production 路径不自动生成 embedding。

### 其他基础设施

- `src/ai/` 厂商无关契约层（Completion / Embedding / Rerank 三职责 Protocol、
  冻结结果 dataclass、统一异常族）。
- Qwen 适配器注入式传输层；未配置时默认传输拒绝发起任何真实网络请求。

## 三、Retry 策略（正式固化）

- application runtime 当前正式策略：**`max_extra_attempts = 0`**，即 retry = 0。
- `src/ai/qwen_client.py` 中库级 `MAX_EXTRA_ATTEMPTS = 2` 保留，仅作为未显式覆盖时
  的库层默认值；`application_ai_provider()` 显式传入 0 覆盖之。
- 无递归重试、无 Agent 循环；仅有线传输级重试且当前 runtime 关闭之。

## 四、真实验证与评测（人工）

- Phase 10C/10D/10E：真实 retrieval / hybrid fusion / 自然语言 hybrid 链路验证，
  详见对应 evidence 文档。
- Phase 11C：真实浏览器 UI 端到端 mixed retrieval，exactly-1 query embedding。
- Phase 11D：最小 retrieval benchmark（5 条 frozen query），**OVERALL PASS**：
  Hybrid 5/5 PASS、无退化，Q3 语义改写型查询明确改善。
- 全部真实调用均在隔离 staging 实例上完成，production 数据零污染。

## 六、边界与已知限制

- 本地单用户、无注册/登录/账户/多租户/云同步；默认绑定 `127.0.0.1`。
- AI 能力需显式配置 API Key 与 `ai_mode=api` 才会启用；默认完全离线。
- Qwen rerank 通道尚未接入（`rerank` 当前 `raise AIUnavailableError`），留待后续。
- 页面向量索引仍为受控付费能力，production 不自动执行。
