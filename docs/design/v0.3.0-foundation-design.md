## 4. 四类笔记定义

| 类型 | 归属 | 必备内容 |
|---|---|---|
| `document` 文档级 | `document_id`（`page_id` 为空） | `personal_note`，数量不限 |
| `page` 页面级 | `page_id`（`document_id` 为空） | `personal_note`，每页可多条 |
| `text_selection` 文字选区级 | `page_id` + 文本锚点 | 原文快照、用户摘录、个人笔记三分离 |
| `image_region` 图片区域级 | `page_id` + 图像锚点 | 原始 PNG 宽高、SHA-256、像素矩形、个人笔记 |

页面类笔记所属文档一律经 `pages.document_id` 连接查询得到，`notes` 表不冗余保存。

## 5. 术语：原文 / 用户摘录 / 个人笔记

| 术语 | 定义 | 存储 | 可改性 |
|---|---|---|---|
| 原文 | 来自 PDF 文本层或 OCR 初稿的来源数据，只读 | 权威源：`pages.extracted_text` / `pages.ocr_text`；选区笔记内 `source_excerpt_snapshot` 仅为创建/重绑时刻的只读副本 | 任何笔记写路径不得修改 |
| 用户摘录 | 用户从原文中主动选取并整理的内容 | `notes.user_excerpt` | 可改；改动不得触碰偏移、快照、来源哈希 |
| 个人笔记 | 用户自行输入的判断、说明、想法 | `notes.personal_note` | 可改 |

笔记功能任何写路径不得触碰 `pages.extracted_text`、`pages.ocr_text`、`pages.markdown_content`、Markdown 文件、PDF、PNG、`evidence_items`。UI 固定文案三分区：「原文（只读）」「用户摘录」「个人笔记」。

## 6. 最终 notes 表 Schema 5 SQL 草案

```sql
-- Schema 5: 结构化笔记基础（统一主表）
CREATE TABLE notes (
    id            INTEGER PRIMARY KEY AUTOINCREMENT,
    note_type     TEXT    NOT NULL
                  CHECK (note_type IN ('document', 'page', 'text_selection', 'image_region')),
    document_id   INTEGER REFERENCES documents(id) ON DELETE CASCADE,
    page_id       INTEGER REFERENCES pages(id)      ON DELETE CASCADE,

    personal_note TEXT NOT NULL CHECK (length(personal_note) BETWEEN 1 AND 20000),

    -- text_selection 专属锚点
    source_kind              TEXT CHECK (source_kind IS NULL
                                         OR source_kind IN ('pdf_text', 'ocr_text')),
    source_page_text_sha256  TEXT CHECK (source_page_text_sha256 IS NULL
                                         OR length(source_page_text_sha256) = 64),
    source_excerpt_snapshot  TEXT CHECK (source_excerpt_snapshot IS NULL
                                         OR length(source_excerpt_snapshot) BETWEEN 1 AND 20000),
    selection_start INTEGER,
    selection_end   INTEGER,
    user_excerpt    TEXT CHECK (user_excerpt IS NULL
                                OR length(user_excerpt) BETWEEN 1 AND 20000),

    -- image_region 专属锚点
    region_image_sha256 TEXT CHECK (region_image_sha256 IS NULL
                                    OR length(region_image_sha256) = 64),
    region_image_width  INTEGER,
    region_image_height INTEGER,
    region_x0 INTEGER, region_y0 INTEGER,
    region_x1 INTEGER, region_y1 INTEGER,

    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL,

    -- 归属互斥
    CHECK (
        note_type = 'document'
        AND document_id IS NOT NULL
        AND page_id IS NULL
    OR
        note_type IN ('page', 'text_selection', 'image_region')
        AND document_id IS NULL
        AND page_id IS NOT NULL
    ),

    -- 锚点字段类型互斥与组合合法
    CHECK (
        note_type IN ('document', 'page')
        AND source_kind IS NULL AND source_page_text_sha256 IS NULL
        AND source_excerpt_snapshot IS NULL
        AND selection_start IS NULL AND selection_end IS NULL
        AND user_excerpt IS NULL
        AND region_image_sha256 IS NULL
        AND region_image_width IS NULL AND region_image_height IS NULL
        AND region_x0 IS NULL AND region_y0 IS NULL
        AND region_x1 IS NULL AND region_y1 IS NULL
    OR
        note_type = 'text_selection'
        AND source_kind IS NOT NULL
        AND source_page_text_sha256 IS NOT NULL
        AND source_excerpt_snapshot IS NOT NULL
        AND selection_start IS NOT NULL AND selection_start >= 0
        AND selection_end IS NOT NULL AND selection_end > selection_start
        AND length(source_excerpt_snapshot) = selection_end - selection_start
        AND user_excerpt IS NOT NULL
        AND region_image_sha256 IS NULL
        AND region_image_width IS NULL AND region_image_height IS NULL
        AND region_x0 IS NULL AND region_y0 IS NULL
        AND region_x1 IS NULL AND region_y1 IS NULL
    OR
        note_type = 'image_region'
        AND region_image_sha256 IS NOT NULL
        AND region_image_width  IS NOT NULL AND region_image_width  > 0
        AND region_image_height IS NOT NULL AND region_image_height > 0
        AND region_x0 IS NOT NULL AND region_x0 >= 0
        AND region_y0 IS NOT NULL AND region_y0 >= 0
        AND region_x1 IS NOT NULL AND region_x1 > region_x0
        AND region_y1 IS NOT NULL AND region_y1 > region_y0
        AND region_x1 <= region_image_width
        AND region_y1 <= region_image_height
        AND source_kind IS NULL AND source_page_text_sha256 IS NULL
        AND source_excerpt_snapshot IS NULL
        AND selection_start IS NULL AND selection_end IS NULL
        AND user_excerpt IS NULL
    )
);
CREATE INDEX idx_notes_document ON notes(document_id, updated_at DESC);
CREATE INDEX idx_notes_page     ON notes(page_id, updated_at DESC);
CREATE INDEX idx_notes_type     ON notes(note_type, updated_at DESC);
```

字段上限（已定案）：`personal_note` ≤ 20000 字符；`user_excerpt` ≤ 20000 字符；`source_excerpt_snapshot` 只保存被选中的原文（≤ 20000 字符），不保存整页文本。

## 7. document_id / page_id 互斥归属

- `document` 类型：`document_id` NOT NULL、`page_id` IS NULL。
- `page` / `text_selection` / `image_region` 类型：`page_id` NOT NULL、`document_id` IS NULL。
- 由 §6 的归属互斥 CHECK 声明式保证，无冗余一致性面，无服务层兜底依赖。

## 8. 四类 CHECK 约束

见 §6 SQL，要点：

1. `note_type` 枚举四值；
2. 归属互斥（§7）；
3. 锚点字段类型互斥：非本类型锚点字段必须为 NULL；
4. 选区：`selection_start >= 0`、`selection_end > selection_start`、`length(source_excerpt_snapshot) = selection_end - selection_start`、SHA-256 列恰 64 位；
5. 区域：宽高 > 0、`x0 >= 0`、`y0 >= 0`、`x1 > x0`、`y1 > y0`、`x1 <= region_image_width`、`y1 <= region_image_height`。

## 9. 文字选区单一来源规则（已定案）

1. `pages.extracted_text` 非空 → `source_kind = 'pdf_text'`；
2. 否则 `pages.ocr_text` 非空 → `source_kind = 'ocr_text'`；
3. 两者均为空 → 禁止创建文字选区笔记，UI 引导使用图片区域笔记。

每条选区笔记只绑定一个 `source_kind`。规范来源文本 = 对应列的原始存储值（不做 NFKC/casefold 规范化），偏移空间即该列文本本身。

禁止：拼接 `extracted_text` 与 `ocr_text`；绑定 `markdown_content`；自动在来源之间切换；来源变化后静默重新定位。v0.3.0 不提供用户手动选择文本来源的控件；UI 创建表单固定显示当前来源标签（「来源：PDF 文本层」/「来源：OCR 初稿」）。

注：既有证据篮的混合来源口径（`evidence_basket_service.py` `_original_source_text`）保持不变，选区笔记不复用该口径。

## 10. 文字选区锚点与重新绑定规则

- 创建：用户摘录（初始 = 原文选段）在规范来源文本中**唯一命中**（`str.find` 仅一处）→ 记录 `selection_start/end`、`source_excerpt_snapshot`、`source_page_text_sha256`、来源类型。唯一命中校验由服务层完成（数据库无法验证快照与外部文本的子串关系），自动化测试覆盖。
- 读取：重算当前规范来源文本 SHA-256，与存储值一致 → 偏移可信；不一致 → 显示「来源文字已变化，无法重新定位」，仅展示快照与摘录，不静默改绑。
- 修改 `user_excerpt` / `personal_note`：不得触碰来源类型、哈希、快照与偏移。
- **重新绑定选区**：单事务同时更新 `source_kind`、`source_page_text_sha256`、`source_excerpt_snapshot`、`selection_start`、`selection_end`、`user_excerpt`、`updated_at`。规则：`user_excerpt` 重置为新快照；`personal_note` 保留；`id` 与 `created_at` 不变；不得删除重建；失败整体回滚。
- 重新绑定确认流程：执行前显示旧来源类型、旧原文快照摘要、新来源类型、新原文快照摘要；固定文案「确认重新绑定原文选区：当前原文锚点和用户摘录将替换为新选区，个人笔记内容会保留。」；用户勾选确认 checkbox 后确认按钮才可执行。

## 11. 图片区域坐标、尺寸与 SHA-256

- 创建时读取存储 PNG（`data/pages/<doc>/page_NNNN.png`）实际值并固化：`region_image_width`、`region_image_height`、`region_image_sha256`；坐标 `x0/y0/x1/y1` 为该 PNG 像素空间，左上角原点，x 向右、y 向下。
- 旋转页/横向页：PyMuPDF 渲染已将页面旋转应用到图像空间，存储 PNG 即用户所见方向，坐标无需额外旋转补偿。
- 读取时重查文件存在性、宽、高、SHA-256：任一不符 → 标记「区域绑定可能失效」，展示提示，不静默缩放套用，不自动改绑；宽高相同但哈希变化同样视为失效。
- 显示映射：按 `显示宽 / region_image_width` 等比换算，原始存储值永不变，换算为纯函数。
- **重新框选区域**：单事务同时更新 `region_image_sha256`、`region_image_width`、`region_image_height`、`region_x0`、`region_y0`、`region_x1`、`region_y1`、`updated_at`。规则：`personal_note` 保留；`id` 与 `created_at` 不变；不得删除重建；失败整体回滚。
- 重新框选确认流程：执行前显示新旧区域坐标和页面图像摘要；固定文案「确认重新框选区域：当前图片区域锚点将被替换，个人笔记内容会保留。」；用户勾选确认 checkbox 后确认按钮才可执行。
- 删除区域笔记只删 `notes` 行，PNG 不得被删除或修改。

## 13. 四类 CRUD 规则

通用：沿用 `_connection()` 连接纪律（`PRAGMA foreign_keys=ON`、`busy_timeout=30000`、异常回滚重抛）；创建/修改/删除均为单语句单事务；写前服务层校验目标存在并组装满足 CHECK 的行；写后重读返回。

- 文档级：校验 document 存在；仅 `personal_note` 可改。
- 页面级：校验 page 存在；仅 `personal_note` 可改。
- 选区级：创建与重新绑定规则见 §10。
- 区域级：创建与重新框选规则见 §11。
- 保存结构化笔记不得改变 `pages.review_status`，与整理稿写路径完全隔离。

## 14. 删除与 CASCADE

1. 四类笔记均支持删除：用户显式触发、checkbox 确认、单行 DELETE 单事务、失败显式报错绝不显示成功。
2. 硬删除；不建回收站、不建软删除状态机、不生成恢复文件、不引入 v0.1.3 复杂恢复机制。
3. 删除笔记不得删除或修改：PDF、`documents`、`pages`、页面 PNG、PDF 原始文本层、OCR 初稿、人工修正内容（整理稿）、`evidence_items`、同一来源上的其他笔记。
4. 文档经现有高强度确认流程删除时的两条 CASCADE 路径：
   - 文档级笔记：`documents → notes(document_id)` 直接级联；
   - 页面类笔记：`documents → pages → notes(page_id)` 两级级联。
5. 删除完成后验证：`foreign_key_check` 通过、无孤儿笔记、无部分成功。

## 15. 页面 Markdown 边界

- `pages.markdown_content` 保留为历史"页面整理稿"，v0.3.0 不删除、不迁移其数据。
- 页面级结构化笔记是可创建多条、独立 CRUD 的笔记对象，与整理稿语义不同。
- UI 文案硬区分：「页面整理稿（Markdown）」与「结构化笔记」不得共用按钮文案。
- 保存结构化笔记不改变 `review_status`；整理稿保存行为不变。
- 结构化笔记不进入 `page_search` 全文检索。

## 16. UI 最小入口

全应用仅两个入口；搜索页、证据篮、复核页一律不加笔记入口。

**入口 1 — 阅读页（`pages/2_浏览资料.py`）右栏新增 tab「结构化笔记」**（既有整理稿编辑区文案改为「整理稿-编辑 / 整理稿-预览」）：

- 可折叠「文档级笔记」区：列表 + 创建/编辑/删除；
- 「本页笔记」区：当前页的页面级、选区级、区域级笔记，三分区固定文案显示；
- 创建选区笔记：只读来源文本 + 来源标签 + 摘录输入 + 个人笔记；无文本层时禁用并引导区域笔记；
- 创建区域笔记：图像框选（§12 组件，拖拽矩形）为默认流程，数值输入为高级兜底；
- 每条笔记：编辑、删除确认、重新绑定/重新框选入口（§10/§11 确认流程）。

**入口 2 — 独立「结构化笔记」列表页**：

- 按文档、按类型筛选；每条显示类型、归属、摘录或区域摘要、个人笔记开头；
- 「返回来源」复用 `reader_query_params` 跳回；
- 空状态、保存失败中文提示、来源失效防御性提示。

## 17. 自动化测试门禁

通用（四种类型逐一）：创建、读取、修改、删除；归属互斥 CHECK 全组合；锚点类型互斥 CHECK；错误 `page_id`/`document_id` 被拒；事务回滚零部分写入；文档删除双路径级联后无孤儿、`foreign_key_check` 通过、无重复删除异常；原文列零改动；同页/同文档其他笔记零影响。

选区专项：快照/摘录/个人笔记分别落库；单一 `source_kind` 绑定；唯一命中校验；来源变化 → "无法重定位"提示且不改绑；改 `user_excerpt` 后偏移/快照/哈希不变；重新绑定单事务七字段（§10）同时更新、`user_excerpt` 重置、`personal_note` 保留、`id` 不变、失败整体回滚；无文本层页面拒绝创建。

区域专项：宽高+SHA-256 原样存取；宽高不变但 PNG 内容变更 → 失效标记；PNG 缺失 → 失效标记；缩放映射纯函数；旋转/横向页；越界坐标与无效矩形被拒；重新框选单事务八字段（§11）同时更新、失败整体回滚；删除后 PNG 存在且哈希不变。

迁移（Schema 4 → 5）：`documents`/`pages`/`page_search`/evidence/Markdown/全部文件零变化（指纹比对）；失败注入整体回滚；迁移前自动备份保留；`integrity_check`/`foreign_key_check` 通过；v0.2.4 全套回归 + `ruff check` 通过。

7. 重新绑定/重新框选确认流程：新旧摘要显示正确，未勾选 checkbox 时按钮不可执行；
8. 编辑未保存切换页面有脏标记提示；保存失败显示中文错误、无假成功；
9. 删除需确认、确认后消失，同页其他笔记与整理稿完好；
10. 删除文档（既有标题确认流程）后其笔记全部消失、`foreign_key_check` 通过；
11. 正式数据隔离：开发实例独立数据目录，不连正式库；**开发端口固定 8520**，8501 正式服务不被触碰；
12. 升级演练：v0.2.4 数据目录副本 → v0.3.0 自动备份+迁移 → 建四类笔记 → 验证降级路径与文案。

## 19. 迁移、备份和降级

- 迁移：纯增量（一张表 + 三索引 + `schema_migrations` 写 5），单事务；前置 version=4 + integrity 通过 + 迁移前自动备份成功；失败回滚，原库与备份双保留；仿 v4 加 core-data fingerprint 自证不碰既有数据；无 down-migration。
- 旧备份：v0.3.0 不改恢复核心逻辑；Schema 5 程序拒绝直接恢复 Schema 4 备份；用户须先用 v0.2.4 恢复旧备份、再由 v0.3.0 升级；升级前自动备份作为降级依据。
- 降级：库为 v5 后 v0.2.4 拒绝打开（既有行为）；降级路径 = 用 v0.2.4 恢复升级前备份；**降级丢失升级后新建的全部结构化笔记**，该事实写入升级提示与运行说明。

## 20. 止损规则

任一笔记类型连续两轮仍无法保证创建、读取、修改、删除完整数据一致性时，**立即停止该实现链**：缩减实现复杂度、更换更确定的交互方式、或延期 v0.3.0 收口。**禁止以"只能创建、不能修改或删除"的残缺状态发布**；删除能力是 v0.3.0 的必要组成部分。

其余止损线：为笔记引入复杂状态机；需要 LangGraph 维持流程；结构化笔记与整理稿语义在 UI 上无法区分；入口超过两个或出现重复流程；删除逻辑可能造成原内容与恢复副本同时丢失；迁移无法可靠兼容现有备份；自动化通过但独立反例持续出现数据损失；为兼容废弃功能不断增加分支逻辑。
