## Security / Abuse Controls

- **HTTP DTO authority**：`AgentRunRequest` 仅 `text: StrictStr` + 可选
  `correlation_id`（1-128 `[A-Za-z0-9._-]`）；`extra="forbid"`；client 不能控制
  tool/service/method/model/provider/base_url/api_key/retry/budget/filesystem
  path/database path/permission/role/system prompt；`request_id` 由 server 生成。
- **Public response privacy**：只投影 `request_id/status/answer/grounded/
  citations/warnings/error`；无 trace/token_usage/model/context_stable_ids/
  error.detail/raw provider response/ToolResult/Decision 内部字段/路径/SQL/secret。
- **Body-byte limit**：`IngressSecurityMiddleware` 按 actual ASGI received bytes
  计数，512,000 bytes 精确上限；declared Content-Length 超限先行拒绝；每 chunk
  检查后才 append；overflow → 413 且不进入下游。container probe：512,001 bytes
  → 413。测试覆盖 Content-Length spoof / chunked / multibyte / 边界。
- **Agent text limit**：`AgentRequest.__post_init__` 权威 120,000 chars；HTTP
  route 通过 request_factory 构造，超限 → 422 invalid_request。与 512KB ingress
  分离，任何 HTTP path 都不能绕过。
- **Rate limiting**：Agent 10/min/IP 默认，Source 60/min/IP 默认；`/health`、
  `/ready` 豁免；OPTIONS 不消耗业务 quota；in-process limiter 线程安全
  （Lock + 60s fixed window + 10,000 key 上限 fail-closed）；per-app 隔离；
  invalid body / invalid stable-id 照常计费；伪造 XFF 不能换桶。
- **Concurrency admission**：`BoundedSemaphore` 默认 4，配置 1..8；满 → 429
  `concurrency_limited` fail fast，无 queue / 无等待；try/finally 释放（成功、
  FAILED、异常路径均释放）。Agent rate limit 与 concurrency limit 独立。
- **CORS**：默认空 allowlist；显式 origin（HTTPS 任意、HTTP 仅 loopback）；
  no wildcard；`allow_credentials=False`；preflight 由 CORSMiddleware 在
  rate/body/DB/Agent 之前处理且不消耗 quota。

## Client-IP / Trusted Proxy

- 默认只信任 immediate socket peer；`X-Forwarded-For` 仅在 immediate peer
  属于显式 trusted CIDR 时被读取；`Forwarded` / `X-Real-IP` 永远忽略。
- XFF 解析：单 header、≤4096 bytes、≤32 hops、ASCII printable、完整链校验、
  right-to-left 跳过 trusted hops 选第一个 untrusted；invalid/duplicate/
  oversized/全 trusted → fallback 到 direct peer；invalid peer → 固定
  `unknown-peer` 桶（不产生攻击者可控新桶）。
- Uvicorn：`proxy_headers=False`、`forwarded_allow_ips=""`，不提前改写
  `scope.client`。
- 结论：**untrusted peer + forged XFF 不能产生 rate-limit bypass**；
  安全默认成立。空 trusted proxy list 的真实后果是「所有用户可能共用 edge
  peer 桶」（availability/usability 问题，非 spoof bypass）——记为 WP6
  platform validation requirement。

## AI Cost Controls

四层独立，不混同：

1. Agent logical ceiling：Decision ≤1 + Final ≤1（≤2 次逻辑模型调用）。
2. HTTP rate limit：10 agent runs/min/IP 默认。
3. Active concurrency：4（1..8），429 fail fast。
4. Finite AiBudgetGuard：`HostedDatabaseAiBudgetGuard` 日/月 UTC 窗口，
   0=unlimited 仅允许单周期；Hosted (0,0) → readiness fail。
5. Hosted transport retry 默认 **0**（`EKB_AI_MAX_EXTRA_ATTEMPTS` 0..2，
   Local 保持 2 不变）。

## AI Budget Concurrency Analysis

**问题**：`HostedDatabaseAiBudgetGuard` 基于已持久化 `ai_calls`（仅
`status='success'` 的 total_tokens）做 preflight check，不是 reservation
system，也不是并发 in-flight strict cap。多个并发请求可能同时通过 check，
在 usage 落账前发出调用，导致累计 token 短暂超过 nominal budget。

**A. 是否可导致明显超预算？** 可导致**有界**超预算，不是无界。每次 check
后马上有 4 个并发槽位可同时进入；usage 落账后下一波调用会被拒绝。

**B. 上界大致受什么限制？**

- `max_active_agent_runs = 4`（并发槽位硬上限）；
- 每 run 逻辑模型调用 ≤2（decision ≤1 + final ≤1）；
- decision 输入 = user text ≤120,000 chars + tool catalog；decision 输出 ≤128
  tokens（`DEFAULT_DECISION_MAX_OUTPUT_TOKENS`）；
- final 输入 = question + context package（≤120,000 chars aggregate）；final
  输出 ≤512 tokens（`DEFAULT_FINAL_ANSWER_MAX_OUTPUT_TOKENS`）；
- Hosted transport retry = 0（不再放大）。

极端对抗下每 run 理论 token 峰值约 2 ×（~120k 输入 tokens + 输出 cap），
4 并发一轮的理论超预算上限约 **~4 × 单 run 峰值**（约数十万 token 量级）；
正常演示问题远低于此。**总超预算量受 concurrency × per-run ceiling 约束，
有界，不是无限烧钱。**

**C. 对匿名比赛 Demo 而言**：**MINOR**。有限预算 + 有界并发 + 有界单步 +
0 retry 使该 race 无法形成不可控成本；Demo 期短且预算可留余量。不构成进入
WP6 的 blocker，也不需要架构重开（reservation 已在 ADR-007 D9 明确 deferred）。

**D. WP6 是否需动作**：建议（非强制）——预算按峰值留余量、或将
`EKB_MAX_ACTIVE_AGENT_RUNS` 调低（如 2）、或部署层叠加保护；无需改生产代码。

## Operational Risks

- **Log growth**：Hosted file log append-only，无自动 rotation。这是 deployment
  operational requirement，不是发布 blocker；WP6 必须有 persistent-volume
  capacity / log retention / monitoring / restart-rebuild 策略，避免无界磁盘
  耗尽（OBSERVATION）。
- **SQLite replica**：多 replica 共享同一 SQLite persistent disk → **FORBID**。
  WP6 必须可验证 replica=1；目标平台无法保证 → 该平台 NO_GO。
- **Proxy trust**：在未知实际云 proxy CIDR 前，application 保持
  secure-by-default；空 trusted list 的代价是 per-client rate-limit quality 下降
  （共享 edge peer 桶），不是 spoof bypass。WP6 配置实际 CIDR 或记录共享桶决策。
- **Single replica risk**：container 单 process/worker 已冻结；真实平台自动
  horizontal scale >1 → NOT ALLOWED，WP6 验证。
