# Engineering Knowledge Base v0.4.1 发布说明

版本定位：**Evidence-grounded Prompt Package**
（基于已确认证据的引用提示词包）

## 本版重点

1. **证据 → 提示词闭环**：证据篮新增“生成引用提示词包”，把人工确认过的证据
   在本地生成 citation-grounded 提示词包，用户自行复制给外部 AI 工具。
2. **只信已确认**：只有 `confirmed` 状态的证据进入 Prompt Package；未确认证据
   不会混入，证据篮页面明确显示总数 / 已确认 / 未确认数量。
3. **生成前必校验**：生成前对每条已确认证据执行既有 source validation；
   任一来源失效（文本哈希变化、区域图像锚点失效、文档或页面缺失）整包
   fail closed，不静默跳过、不自动修复。
4. **三类证据诚实表达**：文字选区输出选区正文与可信度标识；整页证据输出
   当前整页文本并明确标识为当前文本；图片区域只输出文档、页码、图像尺寸与
   区域坐标。

## 图片区域的明确边界

纯文本 Prompt Package 不包含图片像素。EKB 不会 OCR 图片区域、不会自动生成
图片描述、不会把用户备注当作图片中的事实；提示词中明确要求模型不得根据区域
坐标、尺寸或备注猜测图片内容。如需模型分析该图片区域，由用户另行提供对应图片。

## 数据与兼容

- 数据库保持 schema v7，本版本无迁移。
- `PromptBuilder` 的默认问题与 grounding policy 抽取为共享定义，供搜索结果
  提示词与证据提示词包复用；既有 SearchResult Prompt 输出逐字节保持兼容。
- 无新增依赖，无网络请求，无 API Key。

## 已知限制

生成后的 Prompt Package 是一次生成的静态结果；后续证据增删或确认状态变化不会
自动清除旧结果。真人 Smoke Test 判定为 ACCEPTABLE，不阻断本版本。“证据变化后
自动清除已生成 Prompt”仅登记为 v0.4.2 candidate（候选，不等于已承诺范围）。

## 边界

- 继续保持本地优先、单用户、离线可用，正式服务仅监听 `127.0.0.1:8501`。
- 不引入账号、登录、权限、云同步或联网必需功能。
- EKB 不自动调用 AI；AI 仍只是未来可选增强层。
- 不自动覆盖原始资料，不自动修改用户笔记，不自动删除原始 PDF 或页面图像。
- 本发布不包含图片导出、多模态传递或任何 v0.4.2+ 功能。
