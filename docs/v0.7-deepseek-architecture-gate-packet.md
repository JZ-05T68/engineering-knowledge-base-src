## C. v0.7 North Star

用户解决真实工程问题 → 检索已有知识 → Agent 组织经验草稿（origin 标注）→
**用户审阅并显式批准** → 确定性受控写入现有 Knowledge Memory（kind=experience）→
幂等、可撤销、可审计、写后立即可被现有 FTS / 检索 / Agent 只读工具复用。

## D. Frozen Architecture（20 bullets）

1. 单步 Agent 不变；决策/工具/重试边界逐字保持（ADR-006）。
2. registry 恰七 READ_ONLY Tool；无第八写 Tool。
3. 写 = 应用层确定性 WriteCommand（`ExperienceWriteCommandService`），非 Tool。
4. 用户是唯一显式 mutation 批准权威；内容/模型/Agent/Tool 输出写权威=0。
5. 模型仅有提案权威；草稿由模型提案、用户批准定稿。
6. 应用服务 = 策略执行（allowlist / 校验 / 哈希 / 键绑定 / 幂等）；DB = 确定性提交。
7. 写仅 Local（`src/runtime.py` 唯一构造点）；Hosted 不 import / 不构造 / 不暴露。
8. 经验 = `knowledge_memory_entries(kind='experience')` 复用；零新读 Tool。
9. 草稿 session-only，零持久化；刷新丢失为明示取舍。
10. ApprovalToken session-only 三字段：载荷哈希 + **逻辑命令键**（N-7）+ 时间。
11. N-7：一次显式 CREATE 批准至多一次逻辑变异（服务级键绑定 × 持久幂等合取）。
12. canonical V1：确定性载荷序列化 + SHA-256，永久协议，4 条黄金向量钉死。
13. 持久幂等命令日志（`experience_command_log`）：同键同载荷=typed 重放；异载荷/异操作=冲突。
14. SUCCESS_ONLY + 审计原子：命令日志与数据写同事务；失败零库内痕迹。
15. 单一 BEGIN IMMEDIATE（服务唯一外层事务；幂等解析先于一切语义校验）。
16. FIELD_BLOCK_LEVEL provenance：恰 10 区块、每块恰 1 行 origin。
17. 恰 4 个持久 origin（user_asserted / direct_observation / agent_organized /
    agent_inferred）；EXISTING_SOURCE_SUPPORTED 为派生态，非第五 origin。
18. N-6：来源关联持久 `relation_kind ∈ {support, context}`（参与批准哈希）；
    context 永不升格支撑；删除后 MISSING_SUPPORT / MISSING_CONTEXT 分立派生。
19. 软删墓碑 `status='deleted'`（无 deleted_at / 无墓碑表）；undo/restore 仅限命令链
    目标（create 日志行资格）；普通读面视 deleted 为不存在。
20. 来源目标 typed FK（page / knowledge_object / evidence）ON DELETE SET NULL +
    stable_id/标题/指纹快照；support=存在+指纹/revision 相等，context=仅存在。

## E. Safety Invariants（fail-closed 门禁；TM §2 SI-1..SI-13 摘录）

1. 内容/模型/Agent/Tool 输出对写的触发与批准权威为零；仅 UI 显式动作发起。
2. 写入载荷 ≡ 批准载荷（payload_sha256 绑定）；变化必须重新批准。
3. 一次批准 ≤ 一次逻辑 CREATE——令牌在场 ∧ 载荷哈希相等 ∧ 命令键 == 令牌绑定键。
4. 同一幂等键永不创建第二条经验。
5. 无 write audit 的成功变异不可达（审计/日志同事务）。
6. 事务失败零残留（经验/链接/provenance/FTS/日志）。
7. registry 恰七 READ_ONLY；executor 单步；写服务对 Agent 结构性不可达。
8. Hosted 不 import/不构造/不暴露写服务；无写端点。
9. undo/restore 仅限受控 create 日志链目标；墓碑只属命令链。
10. 命令日志/审计仅存标识、枚举、哈希、长度、目标与时间——零正文/prompt/密钥/路径。
