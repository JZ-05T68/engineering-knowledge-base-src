## 十、Remaining Design Gap（必须明确）

**Phase 10D 只证明 FTS-compatible normalized query（`"定时器"` 带引号字面形式）下的
real hybrid fusion 可以运行。**

  自然语言分词/引号规范化（UI 路径存在该规范化）；

  装配下 lexical 恒空（`lexical_rank=None`），该 gap 留待 Phase 10E 处理。
