## 三、修正后的结论（依人工审校口径）

### 1. Relative margin —— 仅支持进一步研究，不构成可部署规则

- 实测 `relevant − labelled distractor = +0.082 ... +0.321` 是**有效的实验证据**，
  说明 within-query 相对排序**有信息量**。
- 但这**不是**可落地的 eligibility 规则：production 在运行时不知道哪个候选是
  labelled relevant / distractor。
- **不建立任何可部署的 relative-margin eligibility 阈值。**
- Phase 4 只能评估**运行时可观测量**，例如：
  - top1 − top2
  - top1 − top3
  - 相邻 rank gap
  - score ratio
  - distribution-relative floor / gap
- **尚无任何 production margin 规则获批。**

### 2. D-03 / top_k —— 保留 Phase 2 区分

- Phase 3 仅支持 **bounded vector candidate contribution**（向量候选池有界）。
- **不声称** `top_k=5` 能证明 final search result bounding。
- **D-03 Production status 保持 OPEN。**

### 3. vector_weight —— 0.5 的 fixture 依据被削弱，但 1.0 也不获批

- Phase 3 **削弱**了 `vector_weight=0.5` 的 fixture 派生依据（真实 paraphrase /
  partial-coverage 相似度与 true-rel 差距不大，0.5 可能过度稀释语义收益）。
- 但**不确立 `1.0` 为更优生产值**；production-optimal vector weight 仍 **UNKNOWN**。
- Phase 4 必须通过**真实 hybrid 检索端到端行为**评估 weight。
- **不预选 1.0。**

### 4. D-01 —— 强化结构性结论

- 真实 partial-coverage 页呈强语义相似度（0.52~0.84），直接证伪 fixture 的 "sim≤0"
  假设，说明 D-01 主要是 **indexing coverage problem**，而非 low-similarity 或
  fusion-eligibility problem。
- **生产状态保持 OPEN**；修复方向应转向索引覆盖率，而非融合侧资格门（`sim>0` 在
  真实模型下近似无操作）。

## 四、eligibility strategy 判别

- **absolute threshold**：只能作为挡完全无关页的粗粒度 floor（约 <0.32 安全），
  **不能**分开 paraphrase 与 lexical-overlap。
- **relative margin**：within-query 有信息量，但**需 Phase 4 用运行时可观测量
  重新验证**，不可直接部署。
- **bounded top-k**：可作为向量候选池有界手段（D-03 vector-side），非最终结果界。
- 综合：**当前分布不足以直接冻结任何一种可部署 eligibility 形态；需 Phase 4
  在真实 hybrid 检索端到端路径上用运行时可观测量继续评估。**
