# Engineering Knowledge Base v0.2.2 人工测试计划

本清单覆盖 v0.2.2 本地单页 OCR 的隔离人工验收。测试在隔离环境执行：独立临时数据目录、
临时数据库、专门生成的三页测试 PDF、非正式测试端口（127.0.0.1:8502–8512 中实际空闲者）。
正式服务（8501）与正式数据全程不参与、不触碰。

## 通用前置条件

- 使用隔离测试目录与全新临时数据库；不得使用正式数据库或正式资料目录。
- 隔离实例通过 `streamlit run app.py --server.address 127.0.0.1 --server.port <测试端口>`
  启动，数据与日志路径指向隔离目录。
- 测试 PDF 共三页：第 1 页纯图像英文数字（无文本层）、第 2 页纯图像中文（无文本层）、
  第 3 页可靠 PDF 文本层（至少 20 个有效字符）；记录测试 PDF 的 SHA-256。
- 全程不访问云端 OCR 或任何网络服务，不下载模型。

## MT-01 应用启动与非 OCR 功能

- 操作：打开隔离应用主页，进入资料导入页与待整理页面。
- PASS：应用正常启动；无 OCR 初始化阻塞；启动后未加载 OCR 模型；其他核心功能可访问。

## MT-02 导入临时扫描 PDF

- 操作：导入三页测试 PDF，打开待整理页面查看第 1 页。
- PASS：导入成功；页面 PNG 正常生成；原始文件未被覆盖；第 1 页显示“执行本地 OCR”按钮。

## MT-03 英文数字单页 OCR

- 操作：在第 1 页点击“执行本地 OCR”，观察 spinner，记录首次耗时，查看完成反馈与
  OCR 初稿。
- PASS：只处理第 1 页；spinner 正常显示；首次加载不卡死；显示“本页 OCR 已完成”；
  OCR 初稿含 `STM32`、`ADC` 等稳定内容；标注“未经人工核验”；文本框只读；执行后不再
  显示默认重复执行按钮；Markdown、review_status 与页面 PNG hash 均未变化。

## MT-04 中文单页 OCR

- 操作：切换第 2 页，执行本地 OCR，查看结果。
- PASS：只处理第 2 页；OCR 初稿能识别主要中文内容（允许少量错字，但必须证明中文模型
  可工作）；第 1 页结果不变；不串页；界面不显示本机路径。

## MT-05 可靠文本层页

- 操作：切换第 3 页，查看 OCR 按钮状态；如按钮存在，点击一次。
- PASS：页面被判定为不符合 OCR 条件；不调用真实引擎；不修改页面数据；不显示系统错误。

## MT-06 OCR 搜索

- 操作：搜索第 1 页 OCR 中的稳定英文关键词；搜索第 2 页稳定识别出的中文关键词。
- PASS：搜索命中正确页面；命中字段来源标注为 OCR；摘要来自 OCR 文本；其他页面不误命中。

## MT-07 OCR 证据警告

- 操作：将第 1 页 OCR 文字加入证据篮，导出证据包查看。
- PASS：选区归入既有原始材料类别；证据包显示 OCR 初稿警告，提示未经人工核验、以原始
  页面图像为准；页面引用、页码信息正常。

## MT-08 数据保护

- 操作：对临时数据库执行只读检查，并核对文件哈希。
- PASS：`extracted_text` 未被 OCR 覆盖；`markdown_content`、`markdown_path` 未变化；
  `review_status` 未自动变为已复核；`ocr_text` 仅写入对应页面；处理状态为
  `ocr_completed`；其他页面不变；原始 PDF 与页面 PNG 的 SHA-256 不变。

## MT-09 第二次点击与重复保护

- 操作：再次打开已有有效 OCR 的页面。
- PASS：不显示执行按钮（或按钮明确不可用）；不发生第二次识别；不覆盖第一次 OCR 结果；
  不产生重复错误或状态。

## MT-10 日志与网络

- 操作：检查隔离实例日志与进程行为。
- PASS：无 HTTP 请求、无模型下载、无 API Key；无 traceback 泄露到页面；初始化和识别
  错误均为本地固定文案；正式 8501 未被访问。
