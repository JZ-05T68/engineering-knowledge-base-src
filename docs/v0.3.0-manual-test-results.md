## 分项操作与证据

以下每项的“证据”均为 runtime/v030-manual-gate/ 下可重复执行的脚本；运行方式：
`.venv/Scripts/python.exe runtime/v030-manual-gate/gate_XX_*.py`（cwd 为 D:/ekb-v0.3.0）。

### 1. 四类笔记持久化（gate_01_persistence.py）

- 操作：AppTest 打开阅读页，依次创建文档级、页面级、文字选区（摘录“阀体”）、
  图片区域（模拟拖拽 (85,128)-(340,510)@显示宽 850）笔记；同会话重跑（刷新）断言渲染；
  再以 `subprocess` 启动全新 Python 进程重开同一数据库断言。
- 预期：四类笔记保存成功、刷新仍在、重启仍在。
- 实际：四条保存闪讯依次出现；刷新后四类笔记均渲染（caption/正文核对）；
  新进程中 4 条笔记完整，选区快照“阀体”、区域坐标 (80,120)-(320,480)、
  图像 800x1200 逐项一致。GATE 01: PASS。

### 2. 列表筛选与返回来源（gate_02_list_filters.py）

- 操作：两文档共 6 条笔记（文档1 四类各一 + 文档2 文档级 + 第2页页面级）；
  列表页按文档、类型、组合筛选计数；对文档2 第 2 页笔记点击「返回来源」（st.switch_page 打桩）。
- 实际：筛选计数 2 / 2 / 1 正确；switch_page 目标 pages/2_浏览资料.py，
  跳转参数 document=2、page=2、from_search=0。GATE 02: PASS。

### 3. 长文档与列表性能（gate_03_long_document_perf.py）

- 操作：300 页文档（真实小 PNG），400 条笔记（页面级 300 / 文档级 50 / 选区 25 / 区域 25）；
  计时 AppTest 列表页与阅读页首次渲染（timeout=60）。
- 实际：建样 7.4s；列表页 0.66s（阈值 15s），阅读页 1.17s；列表页显示「共 400 条」，无异常。
  GATE 03: PASS。

### 4. 空白/旋转/横向页（gate_04_blank_rotated_landscape.py）

- 操作：(a) 无任何文字来源的页面打开阅读页；(b) PyMuPDF 真实 PDF `page.set_rotation(90)`，
  经真实 PdfService.process_page 渲染，对比旋转前后 PNG 尺寸，并在旋转 PNG 上建区域笔记；
  (c) 1000x800 横向 PNG 建区域笔记。
- 实际：(a) 警告文案精确匹配「当前页面没有可用文字来源，请使用图片区域笔记。」，
  选区输入框不渲染，区域笔记经模拟拖拽创建成功；(b) 未旋转 834x1250 → 旋转 1250x834，
  区域笔记 region_image_width/height=1250x834、坐标原样保存；(c) 区域笔记
  1000x800、(100,100)-(900,700) 正常。GATE 04: PASS。

### 5. 框选一致性与高级输入标注（gate_05_drag_consistency.py）

- 操作：(a) 解析 experiments/streamlit_image_coordinates_compat/results.md 十二项门禁表；
  (b) 以 venv pytest 复跑 tests/test_image_region_note_ui.py -k "width"；

  12 页码/key 隔离通过；(b) 2 passed（exit=0）；
  (c) expander 标签精确为「高级坐标输入（调试与故障兜底）」。GATE 05: PASS。

- 实际：「来源：PDF 文本层」「来源：OCR 初稿」均正确；变更后警告

### 7. 重绑/重框确认流程（gate_07_rebind_reframe.py）

  个人笔记保留；(c) 新区域摘要显示、勾选前禁用，应用后坐标 (160,240)-(480,640)，
