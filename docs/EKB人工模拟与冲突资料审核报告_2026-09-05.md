模型：`qwen3.8-max`  
测试资料：`EKB测试PDF.pdf`（10 页）、`EKB冲突测试资料_R3-C.pdf`（7 页）

## 一、结论

本轮通过。正式服能够使用两份用户导入、已经由 QW3.8 逐页读完的资料回答问题；遇到数值、原因、报警含义和维护周期冲突时会并列说明资料、版本和原始页码，不再静默选一份。资料中没有轴承型号时，Agent 明确回答“信息不足”，没有编造。

“保存这次问答”的真实语义已经写清楚：保存的是当前一个问题和当前一次回答，保存后可在“我保存过的内容”再次查看，但普通资料问答不会自动把它当成事实。删除原资料后，保存的问答副本继续保留，并在界面上明确提示这一点。

正式库未执行删除。删除、重传、同名不同内容和人工改页均在临时数据库中验证，避免损坏现有资料。

## 四、资料生命周期隔离测试

| 场景 | 人工操作所代表的顺序 | 实际现象 | 结果 |
| --- | --- | --- | --- |
| 删除资料 | 导入 → Agent 读完 → 提问 → 保存问答 → 删除原资料 → 再问 | 文档、页面、页面搜索记录和该文档的 Agent 阅读文件一起删除；保存的问答副本仍在，但文档和页码关联变为空；普通资料问题不从该副本偷取答案 | 通过 |
| 删除后重传 | 删除 → 重新导入同一 PDF → 先提问 → 再让 Agent 读 | 重传生成新的文档编号；读之前 Agent 不使用它；读完 10 页后重新回答 `EKB-VERIFY-9F27K` 并引用第 8 页 | 通过 |
| 原文件仍在时重复上传 | 同一文件再次导入 | 按 SHA-256 识别为重复，不再保存和重复处理 | 通过 |
| 同名不同内容 | 文件名相同、PDF 字节和 SHA-256 不同 | 作为新资料保存，使用新的文档编号、原文件路径和哈希；不会覆盖旧资料 | 通过 |
| 修改页面后重读 | 把维护周期从 500 小时人工改为 350 小时 | 修改立即使旧阅读结果失效；重读前 Agent 不使用过期页；再次阅读时只重读改动的 1 页，之后回答 350 小时并引用该原始页码 | 通过 |
| 删除过程意外中断 | 文件先进入可恢复隔离区，数据库删除前模拟中断 | 文档原文件、页面图片和 Agent 阅读文件都能恢复；不会留下半删状态 | 通过 |

## 五、本轮发现并修改的代码

1. `pages/0_知识Agent.py`
   - “保存这次对话”改为“保存这次问答”。
   - 明确只保存当前问题和当前回答，且不会自动改变以后回答。
   - 同一回答引用多份资料时，新保存卡片标题改为“关于 2 份资料的讨论”，避免只显示第一份资料造成误解。
2. `pages/15_知识记忆.py`、`src/knowledge_memory_ui.py`
   - 页面名称和内容保持普通语言。
   - 明确删除原资料后，手动保存的副本仍会保留。
3. `src/agent/decision/prompt.py`
   - 泛问参数、代码含义、故障原因、时间和周期时，同时检索版本、修订和适用条件，避免只找到一个孤立结论。
4. `src/ai/rag_prompt_builder.py`
   - 禁止在冲突资料间静默选择、拼接或平均。
   - 要求每个结论绑定资料标题、原始页码、版本或适用环境。
   - 来源编号只能使用上下文已有编号，减少回答被引用校验拒绝的情况。
   - 已指定版本时只回答该范围；普通用户回答尽量短，避免被截断。
5. `src/document_deletion_service.py`、`src/deletion_recovery.py`、`src/runtime.py`
   - 删除资料时同步清理该资料的 QW3.8 页面阅读文件。
   - 这些文件进入同一可恢复删除流程；失败时可回滚，而且不会误删其他资料的阅读结果。
6. 测试与审计
   - 增加删除后记忆污染、删除后重传、同名不同内容、人工改页重读、多资料保存标题、冲突回答规则和删除恢复测试。
   - 增加真实 QW3.8 十题审计脚本，并输出逐题 JSON 记录。
