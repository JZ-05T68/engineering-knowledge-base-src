## Competition Positioning（非技术定位陈述）

> EKB 是一个本地运行的个人工程知识库：它把你手里的工程资料、
> 解决问题的经验组织起来，用 AI 回答工程问题；每条回答都标注依据、
> 可以点回来源；资料建立后如果发生变化，系统会如实提示重新核对，
> 而不是悄悄继续相信它。核心是五个词：**工程资料 · 工程经验 · AI 问答 ·
> 可追溯来源 · 信任边界**。核心知识管理能力与比赛预置演示可在本地离线运行
> （真实 Agent 模式在启用云端模型时需要网络与 API 配置），资料不上传。

（PPT 一行版：**让工程经验可查、可复用、可回源、可核验。**）

## Architecture Story（评委版，非技术）

> 工程资料整理进知识库后，Agent 收到问题会做三件事：
> **查**——用只读工具在资料、经验和证据里检索；
> **答**——只根据查到的内容组织回答，不自由发挥；
> **证**——给关键结论标注来源编号，来源的标题、类型、位置随时可查；
> 如果某条资料建档之后发生了变化，系统会明确标注「来源发生变化」，
> 提醒重新核对，而不是继续默默相信它。

技术附录（仅备技术问询，不进主叙事）：单步 Agent 内核（一次决策至多一个只读
工具、无重试无循环）；七个只读 Tool（页面检索/知识检索/对象/记忆/溯源/
完整性检查/证据）；Final Answer Stage 生成带引用的回答并逐条校验引用合法性
（引用的 stable_id 必须真实存在，失败整体降级为失败）；Hosted API 为冻结的
`/v0.6` 公共契约（请求/失败/来源 DTO、封闭错误目录），是 Mode 1 的本机入口。
