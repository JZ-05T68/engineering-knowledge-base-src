## 4. Experience Model 数据流

```
用户显式选择知识（知识对象/知识记忆）
    → ContextItemProjector（只读投影）
    → KnowledgeContextPackager（fail-closed 打包）
    → ExperiencePromptBuilder（结构化提示词）
    → CompletionProvider / AuditedAIProvider（一次调用，source_feature="experience_model"）
    → JSON 解析 + 字段/引用校验
    → ExperienceCandidate（结构化候选）
    → AuditedExperienceOutput（只读、内存）
    → UI 只读预览（无保存/写入入口）
```

- Provider 不访问数据库：只接收 prompt 文本。
- 输入必须来自 KnowledgeContextPackage，不绕过 Context/Evidence 层。
- 只处理本次显式选择；无后台/定时/连续调用；无会话记忆。

## 5. 结构化输出契约

`ExperienceCandidate`（`src/models.py`）：title / problem / context / action / result /
root_cause / lesson / applicability / limitations / citations。
无法从上下文确认的字段为空字符串；UI 显示"（不足以判断）"。

`AuditedExperienceOutput`：output_id / task / context_package_id / provider / model /
audit_call_id / generated_at / candidate / warnings / is_mock。

- `audit_call_id` 为 None；durable call_uuid 在 `ai_calls` 台账中，可用
  `source_feature='experience_model'` + `target_refs` 检索（按既有契约复用，不另建体系）。
- `is_mock` 明确区分离线演示与真实模型结果。
