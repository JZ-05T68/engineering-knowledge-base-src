| 模式 | 传输 | 标识 |

- 失败态的「切换到预置离线演示」按失败记录的模式显示，切换是显式动作，从不静默回退。

## State Matrix（全部实现并有 AppTest/单测覆盖）

| 状态 | 呈现 |
| --- | --- |
| idle | 「向你的工程知识库提问」说明卡 + 题卡 |
| submitting/loading | `st.status` 粗粒度演示状态（提交/等待/整理/加载来源），明确为 presentation states，无 fake CoT/trace |
| grounded | ✓ 有依据回答 + 答案 + #N chips + 来源列表 |
| warning | ✓ + ⚠ 来源存在限制 双徽章 + 警示横幅 |
| no-evidence | ○ 未找到可支持资料 + 虚线诚实空态卡 + 换题建议（正向信任特性） |
| failed（业务） | × 本次请求失败 + 封闭错误文案 + 重试 |
| rate-limited | ⏳ 请求过于频繁（429/concurrency_limited） |
| backend-unavailable | ⏻ 本机服务不可用 + 解释 + 重试 + 显式切换 mock（连接失败/503/runtime/provider） |
| source unavailable | 答案不受影响；来源项标注「该来源暂时不可检查」 |

禁止泄露核验：无 traceback/JSON/DTO/内部 ID/路径/provider 信息出现在主 UI。

## Citation Behavior

- **Mode 2**：`citations_detail` 显式提供 `#N` ↔ stable_id 映射 → 正文 `【来源 #N】`
  渲染为可点击蓝色 chip，`display_index` 从 1 开始（契约保证）。
- **Mode 1**：`citations_detail` 字段缺失 → 回退为独立已验证来源列表（数组序），
  `display_index=None`，不猜测正文 #N 对应关系，不解析答案文本（单测锁定该行为）。
- title/label 为 null 时回退 `safe_display_text` → 短格式「页面资料 #N」（不含 UUID）。

## Source Viewer

仅展示安全公开/演示字段：标题、类型产品语言（页面资料/知识对象/知识记忆/证据）、
位置、引用 #N（仅 mock）、anchor 说明（仅 mock）、完整性状态、demo 说明。
不暴露：文件路径、raw DB id、SQL、provider 响应、token 用量、绝对路径。

## Integrity Semantics（Scenario C）

- `changed` → 「来源发生变化」+ 解释「快照不一致……不代表造假或被篡改」
  （禁止 可信/不可信 二元道德断言；单测断言免责文案存在）。
- `demo_note` 明确标注「演示预置状态……不是实时核验结果」。
- Mode 1 无 per-source integrity → viewer 显示「当前模式未提供该来源的完整性状态，
  仅展示来源元数据」。
- 演示中不改真实数据、不用生产 DB。

## Visual Polish & Judge Experience Pass（2026-08-29 追加包）

工作包：`Competition Demo UI — Visual Polish & Judge Experience Pass`。

### 视觉层级（打磨后）

- **单屏叙事**（1920×1080 无需滚动）：品牌头（EKB 徽标行 + 工作台标题 +
  圆点模式徽章 `● 预置离线演示`）→ 运行模式 + 一句话语义 → 提问框 →
  演示场景 3 卡 → 回答卡（问题/徽章/警示/正文/chips）↔ 右栏已验证来源 + 详情。
- **品牌**：单一强品牌块（左上），不重复铺 logo；页内隐藏 Streamlit 原生
  toolbar（Deploy 菜单，页面级 CSS，侧边栏导航不受影响）。
- **色彩**：延续项目主蓝 `#2563eb` + 石板灰中性色 + 语义色（ok 绿/warn 琥珀/
  error 红/muted 灰）；状态从不只靠颜色（图标 + 文字 + 底色三通道）。
- **字号阶梯**：品牌行 12.5 → 标题 26 → 问题/来源标题 18.5/16.5 → 正文 16.5

### 主要视觉变更（before → after）

1. **预设题卡 → 演示场景卡**：主场景改为「A · 参数影响 / B · 历史经验 /
   C · 来源可信度」+ 卡下完整问题文案（去掉 hover tooltip，消除点击后
   tooltip 残留的 Streamlit 痕迹）；备用/排练收进「更多演示问题」折叠区，
   主屏减噪且保持一键可达。fixture 键名永不出现在评委界面（测试锁定）。
2. **模式标识**：徽章加圆点指示（● 琥珀=预置演示 / ● 绿=本机 Agent）；
   文案去术语：radio 由「本机 Agent（/v0.6 HTTP）」→「本机 Agent 服务
   （需先启动）」，caption 移除 `mock_demo`/`loopback`/`/v0.6` 等词
   （单测断言评委可见文案无 jargon）。
3. **选中引用态**：答案区与右栏的来源按钮选中时变主色（primary）+「▸」前缀，
   右栏另加「正在查看 ▸」文字标记——不依赖细边框差异。
4. **来源详情 viewer 重构**：`来源详情 · 已验证` kicker → 标题 → chips
   （类型/位置/引用 #N）→ 蓝色「为什么与回答有关」支持说明块 →
   「来源状态 · …」完整性块 → demo 说明。新增防重复规则：mock anchor 若只是
   “标题 · 页码”复读（场景 A/B）则自动回退为通用支持说明
   「本条回答的已验证来源之一，支撑回答中的对应结论。」；场景 C 的独特
   anchor「完整性检查目标」保留（单测锁定两种行为）。
5. **文案统一**：失败徽章/标题统一为「本次请求未完成」（原「本次请求失败」）；
   空态提示改为「EKB 不会在缺少依据时编造答案。…」；右栏空态加信任语
   「EKB 的关键结论可以回到来源。」；右栏选中占位去掉「（仅展示安全的来源
   元数据）」开发者注解。
6. **加载体验**：保留 4 步粗粒度 presentation 状态（0.35s 步进，mock 秒回不拖节奏）；
   无假流式/假工具日志/布局抖动。
