## FAIL-001

- **发现时间**：2026-09-05 17:2x（CAMPAIGN 内，v0.7.1 Session A 第一次提问）
- **Version**：v0.7.1（recall 规则第一版提示词）
- **Persona**：C / 工程型重度用户
- **Session**：A-01
- **Scene**：8511"问问 Agent"首次输入"上次那台 HLD-750 伺服电机闭环方向反了，当时是怎么处理的？"
- **用户看到什么**：回答就绪，但结论是"资料里没有找到答案……没有在当前知识库中找到可支持该问题的资料"，依据 0 条。
- **用户理解为什么**：会认为"我明明导入过调试记录，系统却说没有"，信任受损。
- **Expected**：召回规则应让 Agent 检索经验/资料并给出依据；无经验时也应尝试资料检索或如实说明"没有找到相关经验"。
- **Actual**：Agent 只调用了 knowledge_search（召回规则与其冲突），落空后直接 NO_EVIDENCE，从未尝试 page_search。
- **Severity**：P1（first-action 稳定失败 + 语义误导）
- **First-action failure**：是
- **Data risk**：无
- **Trust impact**：中-高
- **Root cause**：v0.6 executor 为 ADR-006 冻结的单步架构（最多一个只读工具、无循环）；第一版召回规则要求"先 knowledge_search 再决定"，与单步约束冲突，模型按规则只选 knowledge_search。
- **Fix**：改为单步兼容的条件规则——过去导向措辞（上次/以前/当时/我之前）选 knowledge_search；一般资料事实问题选 page_search；knowledge_search 落空时如实说"没有找到你整理过的相关经验"，禁止谎称"资料里没有答案"。
- **Retest**：Session A-02（见 v0.7.1 报告）
- **Final status**：RESOLVED（提示词修订后同场景行为正常）

## AUTOMATION_LIMITATION-001（非产品缺陷）

- **发现时间**：2026-09-05 17:4x（v0.7.1 Session A）
- **现象**：Playwright `fill()` 修改 Streamlit 文本框后，若用 JS `el.click()` 触发提交按钮，文本框新值不会同步（无 blur 事件），落库的是旧值。Session A 中经验 id=4 的标题因此保存为 AI 原稿标题而非人工修改值。
- **对真实用户影响**：无——真实鼠标/触摸点击按钮会先触发 blur 再触发 click，值先同步。
- **处置**：后续所有 UI 编辑采用 `fill()` + `press("Tab")`（或真实坐标点击）确保同步；v0.7.3 Display-to-Commit Gate 用该方法重新验证多字段编辑落库。
- **Final status**：AUTOMATION_LIMITATION（记录在案，不计产品 FAIL）

## FAIL-002

- **发现时间**：2026-09-05 17:5x（v0.7.1 Session B）
- **Version**：v0.7.1
- **Persona**：C / 工程型重度用户
- **Session**：B-01（8511 重启后的新会话）
- **Scene**：正向召回提问"上次车间那台伺服电机转反了，当时是怎么解决的？"
- **用户看到什么**：回答正确给出处理方法与版本条件，依据面板正确显示"· 经验"与"· 保存的问答"两类来源标签；但回答正文只说"处理步骤如下"，没有说明这是用户自己整理过的经验，且把 Raw Q&A 与经验用同等语气并列（"《关于…的讨论》同样指出……"）。
- **用户理解为什么**：可能以为这是 Agent 从说明书里查到的通用知识，意识不到"这是我自己的经验被参考了"；也可能把保存过的问答副本当成与确认经验同级的证据。
- **Expected**：正文先说明"你之前整理过一条经验……"；引用 Raw Q&A 时说明"你保存过的问答"，语气弱于经验。
- **Actual**：正文无归属表述；raw_qa 与经验并列同权。
- **Severity**：P1（重要语义误导——违反 §22 Raw Q&A 权威边界与 §18 表述边界）
- **First-action failure**：否（召回本身成功）
- **Data risk**：无
- **Trust impact**：中
- **Root cause**：决策提示词的召回表述规则不够强约束，模型自行选择了中性表述。
- **Fix**：提示词强制"凡引用 experience，回答必须先写'你之前整理过一条经验'；凡引用 raw_qa，必须写'你保存过的问答'，且不得与经验并列同权"。
- **Retest**：Session B-02
- **Final status**：RESOLVED（待 B-02 验证）

## FAIL-003
