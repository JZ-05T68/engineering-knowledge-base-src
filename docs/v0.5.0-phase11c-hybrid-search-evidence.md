## 一、产品边界（Phase 11B 冻结，Phase 11C 落地）

- `src/search_mode.py` 承载唯一产品门控：
  - `hybrid_is_allowed(mode, filters, sort)`：仅当 `mode=HYBRID`、所有
    `SearchFilters` 字段为空/默认、且 `sort=RELEVANCE` 时才允许走 hybrid；
    任何筛选或非相关度排序静默退回 keyword 执行，绝不「对 hybrid top-k 后过滤」。
  - `result_source(_for)`：仅暴露粗粒度来源标签
    （`关键词匹配 / 语义召回 / 混合匹配`），绝不暴露原始 rank / cosine / RRF 分数。
  - `auto_execute_allowed`：URL/deep-link/history 恢复时 hybrid 状态**绝不**自动
    触发付费 embedding，必须显式点击；已执行状态不重复执行。
- `src/models.py` 新增 `SearchMode(StrEnum)`（`KEYWORD` / `HYBRID`）。
- `src/search_state.py` 将 `mode` 纳入 URL state 序列化；旧 URL 缺 `mode` 默认 keyword。
- `pages/4_检索资料.py`：新增「检索方式」radar（keyword/hybrid）、`search_executed_projection`
  去重（post-submit rerun 不重嵌）、`hybrid_status_note` 降级注记。

真实预算（以外部计数为准）：

| 通道 | 预期 | 实测 |
|------|------|------|
| query embedding（`qwen3.7-text-embedding`） | 1 | exactly 1 |
| retry / extra attempt | 0 | 0（`max_extra_attempts=0`） |
| LLM（`complete`） | 0 | 0 |
| rerank | 0 | 0（`rerank` 恒 `raise AIUnavailableError`） |
| page embedding generation | 0 | 0 |

### HTTP exactly-1 的证据表述（正式口径）

**由三方交叉验证确认 exactly 1：**

1. **百炼外部 successful-call 计数**：本周期 successful call 恰好新增 1 次。
2. **确定性的单次 Hybrid 网络路径**：`HybridSearchService.search()` 的唯一网络
   出口是 `embed((query,))` → `POST /embeddings` 单次调用；`complete`（LLM）
   不在 hybrid 路径上，`rerank` 恒 raise，`max_extra_attempts=0` 保证无重试。
3. **无失败/降级证据**：本次时段 staging 应用日志中无任何「向量召回不可用 /
   失败 / 退化」warning/info，证明单次调用成功返回、无重试、无降级。

> 说明：`urllib_transport`（`src/ai/qwen_client.py`）本身不记录 HTTP 网络日志，
> 因此「恰好 1 次」**不是**由 staging 日志直接数出；正式口径为上述三重交叉验证。
