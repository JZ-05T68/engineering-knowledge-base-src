## Hosted Product Scope

**Hosted v0.6.0 = Public Read-only Single-tenant Agent Demo。**

精确定义：

- 面向公网的是一个**新的、专用的、单进程 HTTP Agent API**，不是把本地 Streamlit
  应用原样发布；
- 数据是一个**运维方预置、脱敏、公开授权（curated demo corpus）** 的知识库
  （单个 SQLite 数据库），不是任何开发者的私人知识库；
- 对外能力只有：frozen single-step read-only Agent（Question → Decision ≤1 →
  0/1 READ_ONLY Tool → Final Answer ≤1 → citation validation → AgentResponse →
  STOP）、引用/来源元数据只读查询、health、readiness；
- 访问模型 = **匿名公网 demo + abuse controls**；可选部署层共享访问口令；
  **不是多用户系统**；
- 不做 upload、不做任何写类 workflow、不做 backup/export/维护、不做后台任务。

排除项（v0.6.0 Hosted 明确不做）：

- 完整 Local EKB 功能云化；
- 任意公网用户上传私人知识库；
- 完整多用户 SaaS / registration / password / OAuth；
- PostgreSQL / Redis / 队列 / 对象存储迁移；
- 公网 Streamlit 页面发布。

        |
        v

        |

## HTTP/API Boundary

**Decision：Local 保持 Streamlit；Hosted 新增专用 Python HTTP API（FastAPI）。**

v0.6.0 最小 endpoints（不过度设计）：

| Method/Path | 用途 | 语义 |
|---|---|---|
| `POST /v0.6/agent/run` | 提交用户问题，执行 frozen Agent pipeline | 同步返回 AgentResponse DTO；服务端生成 request_id |
| `GET /v0.6/sources/{stable_id}` | 引用/来源元数据（type/title/label，无正文/路径） | 只读，stable_id 严格格式校验 |
| `GET /health` | 进程存活 | 不调 AI、不写库 |
| `GET /ready` | 业务就绪 | 检查 profile/数据根/DB/schema/预算/key；不发 completion |

原则：

- thin HTTP adapter → `SingleStepAgentService` → 既有 domain/service；禁止在
  controller 重写业务逻辑。
- HTTP DTO 复用并投影既有 Python contracts，**不是 unrestricted serialization**。

## Frontend Trust Boundary

- 队友未来的 Agent frontend / Demo UI 一律视为 **UNTRUSTED CLIENT**。
- 客户端提交的 tool / model / file path / budget / role / permission / API key
  一律不信任；server authority 完全由后端决定。
- CORS：显式 allowlist，环境变量配置（逗号分隔 origins）；禁止
  `allow_origins=["*"]` + credentials。默认空 = 同源。
- CSRF：v0.6.0 无 cookie session；若采用部署层 Bearer 共享口令则无 CSRF 面。
  不机械添加 CSRF token。

## Authentication / Access

**v0.6.0 Hosted = Anonymous public demo。**

- 无 registration / password / password reset / OAuth / JWT / session cookie。
- 可选：部署层（edge/reverse proxy）单一共享访问口令（Bearer/passcode），
  由运维配置；**它不是 multi-user identity，不提供 per-user isolation**。
- 滥用缓解依赖：rate limit（IP）+ concurrency limit + finite AI budget。
  这些是 abuse mitigation，不是 security identity。

## Authorization

- Hosted authorization = **server execution boundary 只挂载只读能力**。
- Hosted server 模块**不 import / 不构造**任何写类 service（DocumentService 写路径、
  KnowledgeObject/Memory 写路径、Evidence 确认、backup、export、deletion）。
- 不是“隐藏按钮”，而是代码层不可达。
- HTTP 客户端不能指定 tool_name / handler / side_effect / model / provider。

## SQLite Decision

**Decision：v0.6.0 Hosted 保留 SQLite（schema v12），单进程单 worker，persistent
volume。不迁移 PostgreSQL。**

理由：

- Hosted profile 是 small competition demo + preloaded corpus + 无用户写面；
  工作负载 = 读为主 + `ai_calls` append；
- 7 个 Agent Tool 全部 DB-backed，无需文件资产一致性；
- 现有 `Database` 已是短连接、参数化、WAL、migration 幂等（`src/migrations.py`）；
- 迁移 PostgreSQL 会引入数周 scope，违反“安全、简单、可测试、可演示”目标。

**HARD DEPLOYMENT CONSTRAINT：Hosted API 进程必须单实例、单 worker。**
多 worker / 多进程共享同一 SQLite + 自动 migration + 无协调器 = 明确禁止。

SQLite Hosted 运行条件（冻结）：

- process count = 1；worker count = 1；
- DB 位置 = `DATA_ROOT/database/knowledge.db`（WAL/SHM 同目录）；
- 启动执行既有 idempotent migration（schema v12，不做 v13）；
- 写面 = 仅 `ai_calls` / `ai_outputs` audit append + 运维 seed；
- WAL 保持开启；单 worker 下无需额外 checkpoint 策略（可后续加）；
- backup 期望 = 部署层持久卷快照 / 重建 demo 数据；不实现产品内 backup；
- readiness 必须验证 DB 可读 + schema 版本兼容。

## Storage Roots

- `APP_CODE_ROOT`（应用代码）：**read-only**，Hosted 不写。
- `DATA_ROOT`（环境变量 `EKB_DATA_ROOT`，Hosted 必填）：持久可写，含
  `database/`（knowledge.db + WAL/SHM）与 `logs/`。
- `TEMP_ROOT`（可选）：进程临时文件；v0.6.0 Hosted 无上传故可不设。
- Local 保持现有 repo-relative 默认布局，兼容不变。

## Persistent / Ephemeral Storage

- Persistent：`DATA_ROOT/database/knowledge.db`（业务+审计）、`DATA_ROOT/logs/`。
- Ephemeral：进程内存（runtime trace、request 上下文、concurrency 信号量）。
- Not available in Hosted：raw / pages / markdown / quarantine / backups /
  exports / runtime PID 文件（PID 不落盘）。

## Demo Data Strategy

**Demo corpus = deployment-seeded, sanitized, read-only baseline。**

- 来源：独立的 curated demo 语料构建产物（sanitized demo DB artifact），
  **不是** developer 的 `data/database/knowledge.db`、PDF、PNG、Markdown、backups。
- 首次启动：幂等 seed 或挂载预构建 demo DB；schema-known（v12）。
- 内容：公开授权或合成的演示知识；不含任何真实私人资料。
- 重置策略：替换 DATA_ROOT 下的 DB 或重新初始化；无需产品内 reset API。
- **LOCAL PRIVATE DATA MUST NOT BE DEPLOYED BY DEFAULT（硬安全要求）。**

## Secrets

- `EKB_AI_API_KEY`：**server-side only**，来自环境 / secret injection。
- Hosted 模式**禁止读取 repo `.env`**（防开发者本地凭据被误用）；Settings 以
  `_env_file=None` 构造。
- key 不进入：frontend bundle、HTTP response、JS config、logs、errors、browser
  storage、backup、export、DB。
- 无 `DASHSCOPE_API_KEY` 生产 fallback（现状保持）。

### Missing Secret Startup Semantics

- Hosted server 缺 key 时**进程可以启动**（`/health` = ok）；
- `/ready` = **503 NOT_READY**，reason code `ai_not_configured`；
- `/v0.6/agent/run` 返回结构化 503 `PROVIDER_UNAVAILABLE`（安全消息）；
- 不泄露 key name/value，不使用 developer local credential。

## AI Cost Controls

三层边界，不得混淆：

1. **Agent logical call ceiling**：已冻结（Decision ≤1，Tool ≤1，Final ≤1，总 ≤2）。
2. **AI budget ceiling**：复用 `AiBudgetGuard`（日/月 token 预算）。
3. **HTTP abuse/rate/concurrency control**：Public Deployment 新增边界（下方）。

### Global Provider Budget

- **Hosted production requires finite configured AI budget。**
- Hosted 下 `EKB_AI_DAILY_TOKEN_BUDGET` 与 `EKB_AI_MONTHLY_TOKEN_BUDGET` 不得
  同时为 0（unlimited）；否则 readiness fail closed，reason `budget_not_configured`。
- 具体数值由 environment config 提供；unconfigured unlimited 不得成为 Hosted 默认。

## Rate Limit

- 位置：**API middleware / ingress 层**（Hosted server 内 middleware 为最低保障，
  部署层 edge 可叠加）；不在 domain/service 层实现。
- 身份 key：anonymous demo → **client IP**（经受信 proxy 时使用 `X-Forwarded-For`
  且必须配置 trusted proxy 列表）；可组合可选共享口令。仅 abuse mitigation，
  不是 security identity。
- 保守默认值（可 env 覆盖，缺省用默认值，绝不为 unlimited）：
  - `POST /v0.6/agent/run`：**10 runs / minute / IP**（默认）；
  - `GET /v0.6/sources/*`：**60 requests / minute / IP**；
  - `/health`、`/ready`：exempt。
- 超限 → `429` + safe JSON error（含 `Retry-After`）。

## Request Limit

- 区分两层：**transport body bytes ≠ Agent text chars**。
- HTTP ingress body limit（middleware）：**512,000 bytes**（0.5 MiB）。覆盖
  120,000 字符最坏 UTF-8（中文 ~360KB）+ JSON envelope。
- Agent text ≤ **120,000 chars**：由既有 `AgentRequest.__post_init__` 强制
  （`MAX_AGENT_REQUEST_CHARS`）。
- Agent input 字段白名单：`text`（必填，≤120k chars）、可选 `client_request_id`
  （≤128 chars，`[A-Za-z0-9._-]` 校验，仅 correlation）；禁止 client 提交
  model / provider / api key / max tokens / tool registry / tool name /
  database path / file path。
- request_id：**server 生成**（UUID）；client 值只作 correlation，绝不作为
  run_id / 权限 / 去重 authority。

## Concurrency Limit

- HTTP 层最大 active Agent runs = **4**（进程内 semaphore；env 可调 1..8）。
- 超限行为：**fail fast 429**（不 queue）。不引入 distributed queue。
- 与 SQLite 单 worker 约束一致；AI 同步调用被 admission 限制在常量并发内。

## Logging / Privacy

Hosted logging policy（与既有 Audit contract 对齐）：

- 默认不记录：full user prompt、full evidence、document contents、raw model
  output、API keys、Authorization、absolute paths、stack trace。
- 允许记录：request_id、status、latency、tool_name、safe error type、model name、
  token usage、retry count。
- AI audit ledger（`ai_calls`）与 application/server logs 是两套职责：
  ledger 存 hash/metadata（既有 `AuditedAIProvider`），server logs 存运行元数据；
  不得把“已有 AI Ledger”当作“公网日志已安全”。
- 传统 Local UI/维护/导入路径的 raw exception 日志（Inventory F10）属 Local
  surface；Hosted API 进程不得复用这些写面/日志面。

### Privacy Boundary

- UI/Hosted 页面必须声明（技术边界，非法律文档）：
  “您的问题与必要的知识上下文将发送至所配置的外部 AI provider。”
- 非 Agent 的 RAG/Experience/hybrid 写面在 Hosted 不挂载，故无额外数据外发路径。

## Error Boundary

Hosted API 统一错误 envelope：

```json
{
  "request_id": "<uuid>",
  "status": "failed",
  "error": {"code": "CITATION_INVALID", "message": "safe Chinese message"}
}
```

- 禁止返回：`repr(exception)`、traceback、absolute path、SQL、secret、private data。
- 复用 AgentResponse 已 harden 的错误语义；HTTP 边界独立再做一次 DTO 过滤。
- 未预期异常 → 固定 safe message + 内部日志 error_type + request_id 关联。

## Health

- `GET /health` → `200 {"status":"ok"}`。
- 仅表示 process alive；不调用 AI provider、不消耗 token、不写数据库。

## Readiness

- `GET /ready` 检查（**不发真实 completion**）：
  1. runtime profile valid（显式 hosted）；
  2. `DATA_ROOT` 存在且可写；
  3. database 可读且 schema version 兼容（v12）；
  4. Hosted profile 已初始化（demo DB present）；
  5. AI config present（key 非空）若 Agent 要求；
  6. finite AI budget 已配置（非 unlimited）。
- 结果：`200 {"status":"ready"}` 或 `503 {"status":"not_ready","reasons":[...]}`
  （machine-readable reason codes，无 secret）。
- fail closed：schema incompatible / DB unavailable / key missing / budget
  unconfigured → NOT READY，不对公网接受 Agent 请求。

## Long-running Operations

- v0.6.0 Hosted 无 import / OCR / index / migrate / backup / export 暴露。
- 因此**不需要** background worker / queue / Celery / Redis。
- 长任务与断线续跑问题整体 **DEFERRED**。

## Background Execution

- **v0.6.0 Hosted background execution = NO。**
- 理由：Hosted 只有同步单步 Agent run + 元数据查询；无上传/索引/备份能力，
  不存在需要后台执行的工作负载。不为未来功能提前建设队列。

## Windows / Linux Boundary

- Hosted production runtime target OS = **Linux（container）**。
- Windows-specific 项（BAT/VBS、`service_manager`、ctypes 进程检查、schtasks、
  diagnostic netstat、PowerShell 恢复命令）= **LOCAL_ONLY**，不得进入 Hosted
  runtime 依赖。
- 源码层 Python contracts / pathlib / SQLite / urllib 为 portable；PyMuPDF /
  Pillow / RapidOCR 的 Linux wheel 可用性属 WP5 部署验证范围（v0.6.0 Hosted
  不加载 OCR/PDF 渲染，风险进一步降低）。

## Container Strategy

- **v0.6.0 Hosted implementation 采用 container（概念冻结，本轮不写 Dockerfile）。**
- 理由：reproducibility、Linux runtime、依赖打包、secret/config 注入、DATA_ROOT
  mount、源码树 read-only。
- 约束：单进程启动、env-only 配置、持久卷挂载 `DATA_ROOT`、非 root 运行、
  app root 只读。

## Repository Read-only Principle

- Hosted artifact 假设 application source tree **read-only**。
- 所有 runtime mutable state 进入 `DATA_ROOT`（database、logs）；v0.6.0 Hosted
  无其它写面。
- 禁止 Hosted 依赖修改 repo（不写 `data/`、`logs/`、`runtime/` repo 路径）。

## Persistent Volume Requirement

- **REQUIRED**（因为保留 SQLite）。
- 必须 mount：`DATA_ROOT`（至少 `database/` 与 `logs/` 子目录）。

## Demo Database Initialization

- 方式：**prebuilt sanitized demo DB artifact** 或 **幂等 seed-on-startup**
  （从 curated corpus 构建脚本生成，schema v12）。
- 要求：idempotent、non-private、schema-known。
- 禁止：启动脚本复制 developer production DB / 打开 repo `data/`。

## Audit Persistence

- AI audit 继续写同一 SQLite `ai_calls` / `ai_outputs`。
- 与单 worker Hosted SQLite 兼容（append-only 短事务）。
- 不禁用 audit 来规避问题；audit 查询 UI 在 Hosted 不公开。

## Backup in Hosted

- Local backup/restore ≠ Hosted backup requirement。
- v0.6.0 Hosted = 可重建 demo；backup 由部署层持久卷快照承担；产品内
  backup/restore 不实现、不暴露。

## Export

- **HOSTED DISABLED。** 不开放 arbitrary server-side export path。
- `KnowledgeExportService` / `AILedgerExportService` 的 `export_name` 拼接语义
  保持 LOCAL_ONLY，不得原样暴露为 HTTP 参数。

## Maintenance Features

- diagnostic / restore / migration UI / filesystem maintenance / delete
  reconciliation = **LOCAL_ONLY**（或未来 admin-internal），不得出现在 public API。

|---|---|---|---|
| T1 | anonymous AI cost abuse | finite budget + rate limit + concurrency limit + 2 logical calls/run | New required（WP3） |

| T3 | concurrent Agent overload | concurrency semaphore 4，429 fail fast | New required（WP3） |

## Hosted Security Invariants

- **H1. No private local data by default.** 部署包显式 seed demo data，不复制
  `data/`、PDF、PNG、Markdown、backups。
- **H2. Provider secrets server-side only.** key 不进 client/log/response/bundle/DB/backup。
- **H3. Hosted client cannot select server filesystem paths.** 无任何 path 参数。
- **H4. Hosted client cannot choose Tool/provider/model/credentials.** 只允许
  `text` + 可选 correlation id。
- **H5. Hosted Agent remains READ_ONLY.** 严格 7 READ_ONLY Tools；写面 service 不挂载。
- **H6. No unrestricted AI budget.** Hosted 必须配置有限 token 预算，否则 NOT READY。
- **H7. HTTP request and concurrency are bounded.** body bytes、text chars、rate、并发上限。
- **H8. Errors fail closed and sanitized.** 统一 safe error envelope，无 traceback/path/SQL/secret。
- **H9. Mutable runtime data does not depend on writable repo.** 全部进入 DATA_ROOT。
- **H10. Hosted mode is explicit.** `EKB_RUNTIME_PROFILE=hosted`；禁止环境猜测。
- **H11. Missing security config fails closed.** 缺 key/预算/数据根 → readiness fail，不退回 local。
- **H12. No multi-user private-data claim without actual isolation.**
  v0.6.0 Hosted 明确声明单租户公开 demo，不声称 per-user 隔离。

## D1-D16 Decisions

### D1. Local vs Hosted boundary

- **Decision:** Local = 完整 Personal EKB（现状不变）；Hosted = narrow read-only
  Agent demo（新专用 API 进程）。共有：domain services、Agent pipeline、Tool
  Contract、SQLite schema、AI provider 边界。禁用/替代：upload、write workflows、
  backup/export/delete/maintenance 在 Hosted 全部 DENY 或 LOCAL_ONLY。
- **Rationale:** 当前无 identity/隔离，全量云化 = F01/F02/F04/F06 全部暴露；
  narrow profile 让 6 个 BLOCKER CANDIDATES 变为“不适用”。
- **Repository evidence:** `app.py`、`pages/`、`src/runtime.py`、`src/agent/*`。
- **Implementation consequence:** WP1 profile + Hosted server 模块不挂载写面。
- **Deferred:** 写类 Hosted capability、Local 云化。

### D2. HTTP/API runtime

- **Decision:** Local 保持 Streamlit；Hosted 新增专用 FastAPI API（单进程）。
  最小 4 endpoints（agent/run、sources/{stable_id}、health、ready）。
- **Rationale:** services 已 UI-independent，`SingleStepAgentService.run` 可直接
  复用；Streamlit 自带写页面不宜公网；FastAPI+pydantic 与现有 pydantic-settings
  同族，验证/错误边界成本最低。
- **Repository evidence:** `src/agent/response/pipeline.py:20-36`；全仓无 HTTP framework。
- **Implementation consequence:** WP2 thin adapter + DTO + error envelope。
- **Deferred:** 多 endpoint 业务面、流式响应、WebSocket。

### D3. authentication/access model

- **Decision:** Anonymous public demo；可选部署层单一共享口令（Bearer，由
  edge/proxy 强制）；**不建应用内 auth**。
- **Rationale:** demo 目标不需要身份系统；口令只是访问门槛，不是多用户安全。
- **Repository evidence:** 无 auth 模块/表（`src/migrations.py` v12）。
- **Implementation consequence:** WP3 预留可选 access token 校验 hook；WP1 无 user 表。
- **Deferred:** registration、OAuth、per-user identity。

### D4. user/data isolation

- **Decision:** v0.6.0 Hosted **不支持多用户私有数据**。单租户公开 demo corpus，
  运维方所有；无 per-user isolation / quota / audit scope。
- **Rationale:** 当前 kb_uuid 标识 KB 非用户；完整隔离需要 schema/查询全面改造，
  超出 v0.6.0 scope。
- **Repository evidence:** `src/migrations.py` 无 user 表；`src/database.py` 无 owner
  predicate；Inventory F02。
- **Implementation consequence:** demo 数据公开授权；文档明确声明。
- **Deferred:** 多租户隔离、per-user budget/audit。

### D5. SQLite model

- **Decision:** 保留 SQLite v12；**单进程单 worker**；persistent volume；WAL；
  启动幂等 migration；不迁移 PostgreSQL。
- **Rationale:** 7 Tools DB-backed 且只读；demo 无写争用；迁移成本不匹配 scope。
- **Repository evidence:** `src/migrations.py:13` v12；`src/database.py` 短连接/WAL；
  `src/source_fingerprint.py` 纯 DB。
- **Implementation consequence:** WP4 强制单 worker、DATA_ROOT、DB readiness。
- **Deferred:** PostgreSQL、读写分离、多 worker 协调。

### D6. persistent file storage

- **Decision:** Hosted v0.6.0 持久文件 = `DATA_ROOT/database/knowledge.db`
  （+WAL/SHM）+ `logs/`。raw/PDF/PNG/MD/quarantine/backups/exports =
  **NOT PRESENT**。
- **Rationale:** Agent Tool 全部 DB-backed；最小化文件写面。
- **Repository evidence:** 7 个 adapter 只触 DB；`src/source_fingerprint.py` 只 SELECT。
- **Implementation consequence:** WP4 DATA_ROOT 布局；不建对象存储。
- **Deferred:** 文件资产、对象存储、source 附件浏览。

### D7. uploaded source lifecycle

- **Decision:** **UPLOAD = DISABLED in v0.6.0 Hosted。** 使用 preloaded curated demo
  dataset。无 upload lifecycle/ownership/quota 设计。
- **Rationale:** upload 引入 ownership、去重、容量、parser 安全、temp 并发、长任务、
  保留期 7 类问题；demo 不需要。
- **Repository evidence:** `pages/1_导入资料.py`、`src/document_service.py:204-409`
  的同步全量 import 语义（Inventory F04）。
- **Implementation consequence:** Hosted server 无 upload route；WP 不包含上传。
- **Deferred:** 安全上传、显式用户数据所有权。

### D8. server-side secrets

- **Decision:** 环境/secret injection only；Hosted 禁读 repo `.env`
  （`_env_file=None`）；key 永不进 client/log/response/backup。
- **Rationale:** 现状已是 server-side（`SecretStr`），补 Hosted ownership/rotation
  边界即可。
- **Repository evidence:** `src/config.py:82`、`src/runtime.py:117-158`。
- **Implementation consequence:** WP1 hosted settings；WP3 日志/错误边界。
- **Deferred:** secret rotation、托管 secret manager。

### D9. AI budget/rate abuse

- **Decision:** 三层：Agent ceiling（冻结）→ `AiBudgetGuard`（Hosted 必须 finite）→
  HTTP rate/concurrency（新增）。三者不混。
- **Rationale:** budget≠rate≠concurrency；现有 0=unlimited 不得进 Hosted。
- **Repository evidence:** `src/runtime.py:168-204`、`src/ai/provider.py:536-548`。
- **Implementation consequence:** WP1 readiness 检查 budget；WP3 limiter。
- **Deferred:** per-user quota、预留/结算原子化。

### D10. request/upload limits

- **Decision:** body ≤512,000 bytes（ingress middleware）；Agent text ≤120,000 chars
  （既有）；无 upload limits（upload 不存在）；输入白名单 text + correlation id。
- **Rationale:** 传输 bytes 与文本 chars 分离；120k chars 最坏 ~360KB UTF-8。
- **Repository evidence:** `src/agent/execution/contracts.py:34`。
- **Implementation consequence:** WP3 middleware。
- **Deferred:** upload/egress/aggregate quotas。

### D11. logging/privacy

- **Decision:** Hosted 日志只记元数据（request_id/status/latency/tool/error_type/
  model/tokens/retry）；ledger 与 logs 分责；UI 披露 AI 数据边界。
- **Rationale:** 现有 Agent 路径已 safe（Phase 2D），但传统 UI 日志面（F10）不可
  带入 Hosted。
- **Repository evidence:** Phase 2D diff；Inventory E19/F10。
- **Implementation consequence:** WP2/WP3 日志与错误策略。
- **Deferred:** retention、集中日志、正式隐私文案。

### D12. health/readiness

- **Decision:** `/health` = alive；`/ready` = profile/data root/DB/schema/budget/key
  校验，fail closed；**绝不发真实 completion**。
- **Rationale:** Streamlit health ≠ business ready（F14）。
- **Repository evidence:** Inventory E20/E21；`.streamlit/config.toml`。
- **Implementation consequence:** WP2 实现两 endpoint。
- **Deferred:** 深度依赖探测、容量探针。

### D13. long-running execution

- **Decision:** v0.6.0 Hosted 无长任务（无 import/OCR/index/backup）；同步 Agent
  run + 常量并发；**无 background worker / queue**。
- **Rationale:** narrow profile 不产生长任务负载。
- **Repository evidence:** Inventory F13；`src/agent/execution/executor.py` 同步。
- **Implementation consequence:** 无（WP 不含任务系统）。
- **Deferred:** job queue、断线续跑、取消。

### D14. backup/restore

- **Decision:** Hosted = 可重建 demo；部署层持久卷快照负责恢复；产品内
  backup/restore **LOCAL_ONLY**。
- **Rationale:** 现有 backup 是整库明文目录 + 文件系统 authority，不可公网。
- **Repository evidence:** `src/backup_service.py`、`scripts/restore_backup.py`。
- **Implementation consequence:** Hosted 不挂载 BackupService。
- **Deferred:** Hosted backup 语义、retention。

### D15. demo/public data strategy

- **Decision:** deployment-seeded sanitized demo DB artifact；idempotent；
  non-private；schema v12；reset = 重新 seed/替换 DB。**禁止复制生产 DB。**
- **Rationale:** 硬安全要求 LOCAL PRIVATE DATA MUST NOT BE DEPLOYED。
- **Repository evidence:** `.gitignore` 已忽略 `data/*`；生产 DB 内容未公开授权。
- **Implementation consequence:** WP4 seed 工具 + 部署物说明。
- **Deferred:** 真实公开数据集授权流程。

### D16. mainland-China deployment topology

- **Decision:** **vendor-neutral architecture + PLATFORM REQUIREMENTS**；具体厂商
  不冻结（Zeabur China / EdgeOne Pages 仅 CANDIDATES；Vercel 非默认）。
- **Rationale:** 无外部验证不可冻结厂商；仓库无平台 SDK 依赖。
- **Repository evidence:** requirements 无云 SDK；Inventory F21。
- **Implementation consequence:** WP5 按平台要求打包；WP6 实测可达性。
- **Deferred:** 厂商选型、域名/TLS/ICP、价格。
