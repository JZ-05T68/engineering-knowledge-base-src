# Engineering Knowledge Base v0.2.3 发布说明

发布日期：2026-07-29

## 版本定位

v0.2.3 是 v0.2.x 超长工程文档与非标准页面底座的**最终收口版本**。本版本以测试、
缺陷收敛和发布判断为主，不新增大型产品能力；当前不接入 LangChain、LangGraph 或
真实 AI。Windows 本地、单用户、离线优先的产品定位不变。

- 状态：已完成本地收口（正式发布候选）。
- 最终代码 HEAD：`b7416f98e505a4c16a0f0a3a8872b13318d66afb`。
- 本说明仅记录本地收口状态，不代表已经推送 GitHub 或已经正式发布。

## 主要变化

- 中断恢复加固：导入过程中被强制终止后，raw PDF 与页面 PNG 改为“临时文件 →
  校验 → 原子替换”写入，重试可自动恢复，恢复终态与一次性导入一致。
- 浏览定位修复：连续阅读大量搜索结果时，阅读页页码、查询参数与内部导航状态保持
  同步，不再出现跳转后状态错位。
- 重复导入完全零增量：对已成功导入的相同文件再次导入时，UI 继续显示“该文件已经
  导入”提示，documents、pages、page_search、import_records、raw、PNG 和
  Markdown 全部零增量，既有成功导入记录不被修改。
- 导入诊断完整性：重复探测阶段（SHA 查询、页面列表查询）发生异常时，在数据库
  可写的前提下尽力留下一条 failed 导入记录，错误信息可诊断且不掩盖原始异常。
- 规模验证：300 页混合页面、1000～3000 页逐级导入、强杀中断恢复和每次运行后的
  数据库/文件终态不变量核验均已通过（详见 S3 系列结果文档）。

## 已知边界

- 本地单用户、离线优先；默认绑定 `127.0.0.1`，不暴露到局域网。
- 不提供注册、登录、云同步和多用户权限。
- 不包含 AI、LangChain 或 LangGraph；AI 仍为手动模式。
- 并发同时导入相同文件的既有竞态未在本版本扩大处理，属既有非阻断边界。
- 单文档 10,000 页与全库 100,000 页为既定容量目标，本版本按梯度验证至 3,000 页
  规模；更高档位未在本版全部执行。
