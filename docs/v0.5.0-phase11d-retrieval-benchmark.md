## 三、评分口径

- **Hit@1** = relevance 集合中任一页出现在最终 UI 绝对第 1 名。
- **Hit@3** = relevance 集合中任一页出现在最终 UI 绝对 Top 3。
- 单 query：PASS = Hit@1；PARTIAL = 非 Hit@1 但 Hit@3；FAIL = 非 Hit@3。
- 整体：PASS≥4 且 FAIL=0 → OVERALL PASS；PASS≥3 且 FAIL≤1 → PARTIAL；其余 → FAIL。

## 四、人工实测结果（绝对排名）

### Q1 — `定时器预分频器和自动重装载寄存器的作用`（relevant `{17,18}`）

- Keyword：`18, 17, 19, 40, 5`
- Hybrid：`18, 17, 19, 40, 5`
- Keyword best relevant rank = 1；Hybrid best relevant rank = 1 → **unchanged**
- Hybrid Hit@1 ✅ / Hit@3 ✅ → **PASS**

### Q2 — `GPIO 引脚怎么配置成推挽输出`（relevant `{5}`）

- Keyword：`5, 18, 17, 19, 40`
- Hybrid：`5, 18, 19, 17, 40`
- Keyword best relevant rank = 1；Hybrid best relevant rank = 1 → **unchanged**
- Hybrid Hit@1 ✅ / Hit@3 ✅ → **PASS**

### Q3 — `让数据搬运不需要 CPU 一直参与的技术`（relevant `{40}`）★改善案例

- Keyword：`18, 40`（relevant `40` 排第 2）
- Hybrid：`40, 18, 5, 17, 19`（relevant `40` 排第 1）
- Keyword best relevant rank = 2 → Hybrid best relevant rank = 1 → **improved（2→1）**
- Keyword Hit@1 ❌ / Hit@3 ✅（PARTIAL）
- Hybrid Hit@1 ✅ / Hit@3 ✅ → **PASS**

> 说明：Q3 实际操作顺序因人工误切为 Hybrid → Keyword，但两者结果分别记录，
> 不影响评测口径。

### Q4 — `计数器到达目标值后提醒 CPU 的机制`（relevant `{18,17}`）

- Hybrid：`18, 17, 19, 40, 5`

### Q5 — `编码器转动方向怎么判断`（relevant `{17,19}`）

## 五、整体结论

| 基线 | PASS | PARTIAL | FAIL |
|------|------|---------|------|
| Keyword | 4 | 1（Q3） | 0 |
| Hybrid | 5 | 0 | 0 |

- 满足「PASS≥4 且 FAIL=0」→ **OVERALL PASS**。
- Hybrid 在 Q3 上将 relevant page 40 从 keyword 绝对 rank 2 提升到 rank 1
  （明确 retrieval improvement case）；其余 Q1/Q2/Q4/Q5 best relevant rank 均保持 1，
  无任何目标退化。
- 语义改写型查询（Q3）为 Hybrid 相较 keyword 的净收益；明确关键词型查询持平属合理结果。

## 六、真实调用预算与外部证据

- 模型：`qwen3.7-text-embedding`（thinking 不适用）。
- 每条 Hybrid query 最多 1 次真实 HTTP；`max_extra_attempts=0`。
- **外部证据（百炼控制台，人工确认）**：`qwen3.7-text-embedding`
  successful-call 增量 **exactly +5**。

| 通道 | 预算 | 实际 |
|------|------|------|
| query embedding HTTP | 5 | exactly +5（百炼外部计数） |
| retry / extra attempt | 0 | 0（`max_extra_attempts=0`） |
| LLM（`complete`） | 0 | 0 |
| rerank | 0 | 0（`rerank` 恒 `raise AIUnavailableError`） |
| page embedding generation | 0 | 0 |

> HTTP exactly-5 的正式口径为「百炼控制台人工外部计数」，**不是**由本地
> staging 日志直接数出（`urllib_transport` 不写网络日志）。
