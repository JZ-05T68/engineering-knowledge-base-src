# EKB v0.6.0 Phase 1A — Tool Contract Foundation（实施记录）

- Date: 2026-08-26
- Scope: v0.6.0 Phase 1A（唯一正式后端开发任务）
- Related: `docs/v0.6.0-entry-architecture.md`、`docs/adr/ADR-006-agent-foundation.md`

## Implemented

- 新增 Agent Foundation 最小包：`src/agent/`
- 冻结 Tool Contract 类型（`src/agent/tools/contracts.py`）：
  - `ToolSideEffect`：`READ_ONLY` / `WRITE_REVERSIBLE` / `WRITE_DESTRUCTIVE`
  - `ToolResultStatus`：`SUCCESS` / `EMPTY` / `PARTIAL` / `FAILED`
  - `ToolErrorCode`：与 ADR-006 / entry §8.2 一致的全集（11 个 code）
  - `ToolDefinition` / `ToolInput` / `ToolContext` / `ToolReference` /
    `ToolMetadata` / `ToolError` / `ToolResult`
  - `ToolHandler` Protocol：仅用于 contract 测试的最小可执行边界，未实现 Executor
- 冻结 Tool Registry 与 Phase 1 只读策略（`src/agent/tools/registry.py`）：
  - `ToolRegistry`：`register` / `get` / `contains` / `resolve` /
    `list_definitions`；重复注册 fail-closed；未注册 typed error；
    listing 按 name 排序确定性输出
  - `Phase1ReadOnlyPolicy`：`READ_ONLY_ONLY`
  - `DuplicateToolError` / `UnknownToolError` / `ToolNotAllowedError`
- Tool name 格式冻结：`^[a-z][a-z0-9]*(?:_[a-z0-9]+)*$`，≤100 字符，
  大小写敏感，不允许空；description 非空且 ≤2000 字符
- ToolResult 不变量：
  - `FAILED` 必须携带 `error`
  - 非 `FAILED` 不允许携带 `error`
  - `PARTIAL` 必须至少携带一条 `warning`
- ToolError 安全边界：`message` 为 safe public message；`detail` 为内部
  diagnostic，`to_dict()` 默认不输出 `detail`（`include_detail=True` 才输出）
- 引用 lineage：`ToolReference` 复用既有 stable_id 命名空间与
  `ContextFingerprintState` 值；不新建 citation 模型
- 独立边界：新包不 import Streamlit / pages / provider / database / qwen_client；
  AST 测试静态验证
