# Engineering Knowledge Base v0.3.3 Release Notes

版本定位：**Document Management & Data Safety Decision Gate**
（文档管理与数据安全决策收口）

## 本版重点

1. **独立「文档管理」页**：全量文档清单与统一删除入口，删除确认链从浏览页
   收敛至此。
2. **删除标题精确确认双层防御**：UI 确认链之外，服务层在执行时重读标题做
   严格相等校验，不匹配即零副作用中止。
3. **v0.3.x 人工整理流程最终真人验证**：浏览 → 阅读 → 笔记 → 聚合全链路
   经真人回归通过。

## 用户可见变化

- 新增「文档管理」页：以全量文档清单（标题 / 原始文件名 / 页数 / 状态 /
  导入时间）集中管理已导入文档，按 document id 选择目标文档并复用共享
  删除确认链执行删除；删除成功后清单自动刷新、失效选择自动清理。
- 浏览页「文档管理」内的删除入口收敛：删除确认链迁移至「文档管理」页，
  原位置保留迁移说明与跳转按钮；「保存文档分类」区块不变。
- 删除警告文案按备份语义修正：明确删除作用于当前知识库中的文档及关联
  数据和工作文件，历史备份中可能仍保留旧版本。

## 数据安全

- 删除安全体系沿用 v0.3.2 既有机制：逐操作隔离区（staging）+ 原子 manifest
  + 崩溃后启动对账恢复（recovery），本版未改动该模型。
- `DocumentDeletionService.delete_document()` 新增必填 keyword-only 参数
  `expected_title`：在执行时重新读取的标题上做严格相等校验（不去空白、
  不折叠大小写），不匹配立即中止且不产生任何副作用，与 UI 层确认形成
  双层纵深防御。
- 数据库保持 schema v6，无迁移；v0.3.1 / v0.3.2 数据库可直接打开。

## 运行环境

- 正式 v0.3.3 运行时为仓库本地 `.venv`（Python 3.11.9），不再使用 system
  Python 作为正式运行环境。
- `requirements.txt` 已包含 `streamlit-image-coordinates==0.4.0`；`.venv`
  依赖完整性已验证（streamlit / streamlit-image-coordinates 可导入，
  `pip check` 通过）。
- 正式服务固定监听 `127.0.0.1:8501`；8513–8517 仅为 G3 临时 gate 端口，
  非正式部署入口。

## Known limitations

- 本版要求 **Streamlit <1.61**（沿用 v0.3.2 的依赖兼容限制，
  streamlit-image-coordinates 0.4.0 上游仍依赖 1.61 移除的内部接口）。
- 删除仍为永久操作：本版没有回收站 / 撤销删除。
- G3-03 历史 UI 停滞症状根因未证实；当前受控验证未复现，按既有证据不做
  源码改动。
- 不包含 AI、账号、云同步或联网必需功能。
