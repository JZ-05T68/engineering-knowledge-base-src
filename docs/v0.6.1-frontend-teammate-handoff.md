# v0.6.1 Frontend Teammate Handoff（前端交接包）

目标：15 分钟理解比赛演示页并安全接手。维护者：杨洋。前序执行：GLM-5.3。

## 1. 这个页面在做什么

`pages/0_知识Agent.py` 是创新创业比赛的产品演示面，一个屏幕讲完：

```
问题 → 回答 → 有依据（徽章） → 引用（chips） → 来源详情（右栏 viewer） → 信任边界（完整性/空态/失败）
```

三条主场景（点击即跑，零输入）：A 参数影响（grounded+2 源）、
B 历史经验（grounded+1 源+限制警告）、C 来源可信度（知识对象+changed 完整性）。
默认运行在 **Mode 2 预置离线演示**（确定性 mock 数据，右上角徽章标识），
Mode 1（本机 Agent HTTP）为显式可切模式，失败必须明示、绝不静默伪装。

## 7. 1920×1080 验证方法

浏览器开发者工具 → 响应式模式 → 1920×1080，或直接全屏演示。
检查：首屏含品牌/模式/提问框/3 张场景卡/回答区/来源面板；无横向滚动条；
徽章与状态文字可读。1366×768 下无溢出、CTA 可见即可。

## 8. Mode 1 / Mode 2 语义红线

- Mode 2 界面必须保持「预置离线演示」可见标识（徽章 + 回答卡「预置演示数据」chip），
  不得让 mock 回答看起来像实时模型输出。
- 失败不得伪装成功：Mode 1 连接失败 → 「本机 Agent 服务当前不可用」+
  显式「切换到预置离线演示」按钮，该按钮的行为（重跑当前问题）不得改为静默替换答案。
- 完整性措辞红线：「来源发生变化」，不得写「被篡改/不可信/造假」；
  免责句「不代表造假或被篡改」保留。
- 不新增后端字段依赖；需要新数据（如每源真实完整性）先找维护者走契约评审。
