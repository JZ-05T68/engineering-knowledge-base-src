## A. 如何启动本机 8501 应用

```powershell
# Windows PowerShell（在仓库根目录 D:\Projects\ekb-dev 下执行）
python -m streamlit run app.py --server.port 8501 --server.address 127.0.0.1 --server.headless true
# 健康检查（应返回 200）
curl http://127.0.0.1:8501/_stcore/health
```

- 端口**固定 8501**、地址**固定 127.0.0.1**（`src/config.py` 的
  `OFFICIAL_HOST/PORT` 强制校验，不得改端口、不得绑 0.0.0.0）。
- 也可以用仓库自带脚本：`启动工程知识库.bat`（后台启动）；
  `停止工程知识库.bat`（停止）；`查看运行状态.bat`（状态）。
- 冷启动到 health 200 实测约 1–9 秒。
- 无需 API Key、无需网络、无需任何 `.env` 配置即可运行全部演示。

## G. Mode 1 / 2 / 3 含义

| 模式 | 界面名称 | 含义 | 状态 |

## I. 比赛措辞边界（评委可见文案红线）

- 推荐口径：**让工程经验可查、可复用、可回源、可核验**；
  **依据可查、来源可回、变化会提示**。
- 离线口径：**核心知识管理能力和比赛预置演示可在本地离线运行；
  真实 Agent 模式在启用云端模型时需要网络和 API 配置。**
  （不得写「全程无需联网」——Mode 1 可能需要网络。）
- 禁止：「100%准确」「零幻觉」「完全可信」「实时联网验证」「被篡改/不可信/造假」
  （changed ≠ 篡改；免责句「不代表造假或被篡改」必须保留）。
- mock 必须可识别：「预置离线演示」「预置演示数据」标识不得删除。
- 有依据回答 = 有来源支撑，≠ 必然正确；不得写成保证正确。

## L. 如何安全地停止 / 重启服务

- 前台启动的 Streamlit：在控制台按 `Ctrl+C` 停止；重新执行启动命令即可。
- 用 `.bat` 启动的后台服务：`停止工程知识库.bat` 停止，
  `启动工程知识库.bat` 再次启动；`查看运行状态.bat` 查看状态。
- 直接关掉运行中的控制台窗口同样可以停止前台服务（会话状态在服务端内存，
  重启后演示页回到初始态，fixtures 不受影响）。
- 演示状态复位：页面底部「演示操作 → 重置演示」只清会话状态，
  不触碰数据库、文件与 fixtures；浏览器刷新等效复位。
