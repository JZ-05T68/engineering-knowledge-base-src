## Scope

将四个已有稳定 service 的 READ_ONLY 能力接入 Phase 1A 冻结的 Tool Contract：

1. `page_search`
2. `knowledge_search`
3. `get_knowledge_object`
4. `get_knowledge_memory`

本阶段不实现 Agent、模型决策、multi-step、schema v13、WRITE Tool、UI 或公网部署。

## Existing Services Reused

| Tool | Existing Service | Adapter | Side Effect |
|---|---|---|---|
| `page_search` | `src.search_service.SearchService`（词面 FTS5 页面检索） | `PageSearchAdapter` | READ_ONLY |
| `knowledge_search` | `src.knowledge_search_service.KnowledgeSearchService`（离线 FTS5，对象/记忆分组） | `KnowledgeSearchAdapter` | READ_ONLY |
| `get_knowledge_object` | `src.knowledge_object_service.KnowledgeObjectService.get_view` | `KnowledgeObjectAdapter` | READ_ONLY |
| `get_knowledge_memory` | `src.knowledge_memory_service.KnowledgeMemoryService.get` | `KnowledgeMemoryAdapter` | READ_ONLY |

## Input Contracts

### page_search

Required:
- `query`（string，非空，≤500 字符）

Optional:
- `limit`（integer，1–100，默认 20）

### knowledge_search

Required:
- `query`（string，非空，≤500 字符）

Optional:
- `limit`（integer，1–100，默认 20；每个结果类型分别应用）

### get_knowledge_object

Required:
- `stable_id`（string，格式 `<kb_uuid>:knowledge_object:<id>`）

### get_knowledge_memory

Required:
- `stable_id`（string，格式 `<kb_uuid>:knowledge_memory:<id>`）

所有 Adapter 对未声明参数 fail closed → `INVALID_INPUT`。

## Output Contracts

统一由 `ToolResult` 表达：

- `SUCCESS`：有正常结果；
- `EMPTY`：搜索合法执行但 0 命中；
- `PARTIAL`：`get_knowledge_object` 存在 CHANGED / MISSING / UNKNOWN 来源时；
- `FAILED`：输入非法、未找到、或内部失败，携带 `ToolError`。

各 Tool `data` 为结构化 dict；搜索类包含 `query/limit/total/results`，读取类包含实体稳定字段与来源/关联信息。不返回 Markdown 搜索文本。

## Error Mapping

| 情形 | ToolErrorCode |
|---|---|
| 参数缺失 / 类型错误 / 空字符串 / 越界 limit / 未知参数 / stable_id 类型错误或格式错误 | `invalid_input` |
| 按 stable_id 读取不存在 / 不属于当前 KB | `not_found` |
| 底层 service 未知异常 | `internal_failure`（safe message，不暴露路径/SQL/堆栈/密钥） |
| 搜索 0 结果 | `EMPTY` 状态，不是错误 |

## Reference Mapping

- `page_search`：每个页面命中 → `kb_uuid:page:<page_id>`。
- `knowledge_search`：每个结果直接使用 service 提供的 `stable_id`。
- `get_knowledge_object`：对象自身 stable_id + 可确定性映射的 PAGE / EVIDENCE 来源引用；DOCUMENT / NOTE 来源保留在 `data.sources` 但不伪造 stable_id。
- `get_knowledge_memory`：记忆自身 stable_id + 已关联的 Knowledge Object / Page 引用；Document 仅保留在 `data.document_id`。

禁止伪造引用：没有 canonical stable_id 的来源不会出现在 `ToolResult.references`。

## Hidden-write Audit

- `SearchService.search`：只读 SELECT，无写入。
- `KnowledgeSearchService.search`：只读 FTS5，无写入。
- `KnowledgeObjectService.get_view`：读取对象、来源与关系；来源指纹在内存中重算并与快照比较，不回写（ADR-03）。
- `KnowledgeMemoryService.get`：只读主键查询。
- 测试使用临时 SQLite fixture 断言调用四个 Adapter 前后 DB 文件 SHA-256 不变。
