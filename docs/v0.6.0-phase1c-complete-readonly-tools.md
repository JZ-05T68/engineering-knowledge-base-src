## Provenance Contract

- 输入：`stable_id`，支持 `page` / `knowledge_object` / `knowledge_memory` / `evidence`。
- 输出：subject identity/type、title、status、revision_ref、source_anchors、relation_refs、warnings。
- 不复制正文；只回答“知识来自哪里、能追溯到什么”。
- References 只包含可确定性构造的 stable_id（page / evidence / knowledge_object）；document / note / selection / image_region 锚点保留在 data 中但绝不伪造 reference。
- 无来源锚点或存在 CHANGED / MISSING / UNKNOWN 来源 → `PARTIAL + warning`。

## Source Integrity Contract

- 输入：`stable_id`，支持 `knowledge_object`（查看该对象全部来源）或 `knowledge_source`（查看单个来源链接）。
- 输出：subject、aggregate_state、每个 source 的 source_type/source_id/source_note/integrity_state/fingerprint_version/captured_at/source-link stable_id。
- 只读取当前已记录/当前内存重算比较的状态；**不 refresh、不 recapture、不写库**。
- `VALID` → SUCCESS；`CHANGED` / `MISSING` / `UNKNOWN` → `PARTIAL + warning`；目标不存在 → `FAILED / NOT_FOUND`。
- 新增最小只读 facade：`KnowledgeObjectService.source_view(source_id)`，位于领域 service 包，不依赖 Agent。

## Evidence Contract

- 输入：`stable_id`，格式 `<kb_uuid>:evidence:<id>`。
- 输出：evidence identity/type、confirmation state、document/page anchor、evidence_text、text_kind、from_ocr_text、region metadata、source_locator、references。
- 未确认 Evidence → `PARTIAL + warning`，data 中 `confirmed=false`；已确认 → SUCCESS。
- 不输出页面 PNG 二进制 / base64 / PDF；图片区域只返回结构化 region metadata。

## Read-only Audit

- `inspect_provenance hidden write: NO`
- `inspect_source_integrity hidden write: NO`
- `get_evidence hidden write: NO`

三个 Tool 的调用路径均只读；测试断言临时 DB 文件 SHA-256 在调用前后一致，且 `inspect_source_integrity` 前后 stored fingerprint / captured_at 不变。

## Input / Output Schema

### inspect_provenance

Required: `stable_id`（page / knowledge_object / knowledge_memory / evidence）

### inspect_source_integrity

Required: `stable_id`（knowledge_object 或 knowledge_source）

### get_evidence

Required: `stable_id`（evidence）

所有 Tool 对未知参数 fail closed → `INVALID_INPUT`。

## Error Mapping

| 情形 | ToolErrorCode |
|---|---|
| 参数缺失 / 类型错误 / 空字符串 / 未知参数 / stable_id 类型错误或格式错误 | `invalid_input` |
| 目标不存在 / 不属于当前 KB | `not_found` |
| 底层 service 未知异常 | `internal_failure`（safe message） |

## Reference Semantics

- `inspect_provenance`：subject stable_id + 可映射的 page / evidence / knowledge_object 锚点；不伪造 document / note / selection / image_region。
- `inspect_source_integrity`：subject stable_id + 每个 source link 的 `knowledge_source` stable_id（真实 source 行 identity）。
- `get_evidence`：evidence stable_id + page stable_id；document 仅保留在 data。
