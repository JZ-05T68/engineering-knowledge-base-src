## 冒烟步骤

1. - [ ] 通过启动脚本启动应用，首页正常打开，标题显示“工程知识库 v0.2.0”。
2. - [ ] 在“导入资料”导入普通 PDF：导入完成，页数与实际一致，状态为已完成。
3. - [ ] 导入 100 页以上 PDF：进度持续推进到最后一页，导入结果页数正确，无缺页。
4. - [ ] 在“浏览资料”中浏览该文档的普通页、空白页、短文本页、横向页和旋转页：页面图片
       显示正常，页码与内容对应，长文档翻页不缺页。
5. - [ ] 对一个页面执行“重新处理”：只处理该页并刷新其结果。
6. - [ ] 确认相邻页面的图片、文本和备注在重新处理前后没有变化。
7. - [ ] 确认导入结果、文档页数、页面数量和页面状态显示正常；如导入中存在失败页，文档应
       显示为部分完成而非全部成功。
8. - [ ] 依次打开“检索资料”“浏览资料”“待整理页面”“标签管理”“项目管理”“导入记录”
       “证据篮”“系统维护”，确认各入口正常加载。
9. - [ ] 关闭应用，确认无异常残留进程，临时文件正常清理。

## 通过标准

- 以上步骤全部完成，无报错、无缺页、无假成功、无跨页内容串改。
- 长文档导入与单页重新处理行为符合预期，既有页面入口均可正常使用。

## 备注

- 已知限制（不属于本次冒烟失败）：重新处理失败页成功后，文档级导入状态可能仍显示
  “部分完成”，详见 v0.2.0 发布说明的已知限制。
- 发现问题时记录页面、文档和操作步骤，不要直接在正式数据库上手工修复。
