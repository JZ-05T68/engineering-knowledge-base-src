## 3. B 组执行前：重建、恢复与首次哈希核验流程

1. 确认 8501～8512 无监听、系统无 Python/Streamlit 进程、待删除路径准确为 `D:\ekb-isolated\v0.1.3-3a\`。
2. 删除并重建 `D:\ekb-isolated\v0.1.3-3a\{data,backups,logs,runtime}`。
3. 恢复：
   ```
   .venv/Scripts/python.exe scripts/restore_backup.py \
     --backup backups/pre-expansion-v0.1.2-20260722-164155 \
     --target-data-dir "D:/ekb-isolated/v0.1.3-3a/data" \
     --target-backups-dir "D:/ekb-isolated/v0.1.3-3a/backups" --confirm RESTORE
   ```
   必须输出：预检查 PASS、恢复 PASS、恢复后验证 PASS。
4. **立即**（启动应用、打开任何 SQLite 连接之前）计算 `D:\ekb-isolated\v0.1.3-3a\data\database\knowledge.db` 的 SHA-256，与备份 manifest 中 `data/database/knowledge.db` 记录（`df3bfd91c8fe1e9721df8abff581c13d711ebace5b1f0252c373a3d32cbfe8de`）比对：一致→进入第 5 步；不一致→立即停止上报，不恢复、不修复、不继续。
5. 启动隔离实例（后台）：
   ```

     EKB_RAW_DIR="D:/ekb-isolated/v0.1.3-3a/data/raw" \

     EKB_BACKUPS_DIR="D:/ekb-isolated/v0.1.3-3a/backups" \
   ```

## 4. 职责分工：人工操作 + Kimi 只读核验

环境复核结论：`.venv` 中**没有** Playwright/Selenium（仅 `requests`、`websockets`），系统存在 Edge 与 Chrome；仓库历史上曾用 Edge CDP 做浏览器验收（`runtime/edge-cdp-*`），但当前不存在可直接复用的界面驱动脚本，且本计划不允许安装新依赖。

因此本计划统一定义为**协作模式**：

- **Kimi 自动完成**（全部 21 项共用）：隔离环境重建/恢复/首次哈希核验；隔离实例启动与停止；`netstat`/进程核验；每场景执行前后的隔离库只读（`mode=ro&immutable=1` + `PRAGMA query_only=ON`）统计与内容比对；隔离文件系统计数与哈希比对；B-21 临时 PDF 本地生成；证据记录与最终报告。
- **用户人工完成**（全部 21 项的界面操作）：浏览器中打开 `http://127.0.0.1:8502`，按每项"用户操作步骤"点击；每步后告知 Kimi 实际界面文案。
- Kimi **不**假设任何浏览器自动控制能力；每项步骤均给出最少点击路径。界面文案以第 5 节代码依据为准；执行时若实际文案与引用不符，记录实际文案并标记差异，不当场判定 FAIL（除非语义相反）。

## 6. 分组、顺序与恢复策略

- **执行顺序**（与编号不同，按数据依赖性）：组 A（B-01→B-04）→ 组 B（B-05→B-09，B-08 与 B-09 交错：先关联后删除）→ 组 C（B-10→B-15）→ 组 D（B-16→B-18）→ B-20 → B-21 → **B-19 最后**（破坏性）。
- **共用基线**：除 B-19 外全部场景共用第 3 节恢复的同一份隔离库，状态允许累积；各场景自带前置与衔接方法，无需中途恢复。
- **必须重新恢复干净基线的情况**：仅在执行中触发停止条件、或某场景 FAIL 导致后续前置不可信时，按第 3 节重新恢复并从断点组继续；B-19 放最后即避免为其单独恢复。
- **数据库哈希**：B-01 起所有写场景均改变 db 文件哈希，属预期，不再比对。
- **WAL/SHM**：实例运行期间可能出现 `-wal`/`-shm`；B 组结束正常停止后如实记录最终状态（有/无、大小）；不主动删除。
- **每场景通用核验动作**（Kimi）：执行前快照（相关表计数+目标行哈希）→用户操作→执行后比对→记录实际界面文案。

## 7. B 组统一停止条件

出现任一情况立即停止、保护现场、只记录不修复：

2. 隔离路径解析错误（任何写入落出 `D:\ekb-isolated\v0.1.3-3a\`）；

## 9. 明确排除的测试缺口（本轮不覆盖）
