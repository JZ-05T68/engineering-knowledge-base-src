# 项目发布历史

本文件从项目层面汇总 Engineering Knowledge Base 各版本的主要新增内容、发布状态和
历史结果，面向公开源码仓库的读者。

本文件不替代 [CHANGELOG.md](CHANGELOG.md)：

- `CHANGELOG.md` 继续保存详细的功能、修复和技术变更。
- 本文件只保存便于公开阅读的版本摘要和发布结果，不复制完整测试日志、逐文件修改
  列表、审计过程和实现细节。

## 维护规则

1. 发布历史原则上只在一个新的小版本正式完成时集中更新一次。
2. 支版本（补丁版本）发布期间，详细变化只更新 `CHANGELOG.md`。
3. 下一个小版本正式发布时，再集中整理上一条小版本线中的各支版本。
4. 每个支版本只记录：版本号、发布日期、版本定位、主要新增或变化、发布状态、
   正式 tag 或提交，以及必要的废弃、停止或替代说明。
5. 不复制完整测试日志、逐文件修改列表、审计过程和实现细节。
6. 未发布、停止或废弃的版本必须明确标注，不能写成正式发布版本。

## 状态术语

- **正式发布**：完成发布验收、打有正式 tag 并对外发布的版本。
- **内部迭代**：开发阶段的内部里程碑，没有正式 tag，未对外发布。
- **开发中**：正在进行、尚未完成验收的版本。
- **停止／放弃**：已停止开发、不会发布的版本。
- **未发布**：已有部分工作但未形成正式发布的版本。

## v0.2.x：超长工程文档与非标准页面底座

### v0.2.0

- 状态：正式发布（源码已公开）
- 发布日期：2026-07-24
- 版本定位：超长工程文档与非标准页面处理底座
- 主要内容：
  - 新增单页 PDF 处理接口，页面重新处理只渲染目标页，不再整份重新渲染。
  - 建立确定性页面诊断：空白、短文本、横向、旋转页面由独立标志识别。
  - 新增文档级诊断摘要，聚合一次导入的页面计数与对应页码列表。
  - 验证页级失败隔离：单页失败不中断后续页面，不出现假成功。
  - 完成 300 页混合 PDF 实际规模验收与 120 页长文档自动测试基线。
- 发布标识：tag `v0.2.0`，正式提交
  `6426b39bba3bb6ad0a51c993b9587c03df3065af`
- 备注：本版本未接入 LangChain、LangGraph、OCR 模型或任何外部 AI SDK；核心功能
  继续完全离线可用，不需要 API Key。schema 保持 v4，无数据库迁移。

## v0.0.x：基础能力建设阶段

v0.0.x 各版本均为内部迭代里程碑，没有正式 tag，未对外发布；日期取自 CHANGELOG
与提交记录。

### v0.0.1

- 状态：内部迭代
- 发布日期：2026-07-11（初始提交日期）
- 版本定位：本地知识库最小能力
- 主要内容：
  - 导入 PDF 并将每页渲染为 PNG 页面图像。
  - 有文本层时提取文本，扫描或手写页标记为待整理。
  - 支持页面级人工 Markdown 笔记与文档、页面浏览。
  - 本地全文搜索与面向外部 AI 工具的引用证据提示词包。
  - 元数据使用 SQLite 本地持久化。
- 发布标识：初始提交 `28fd7f5`，无 tag
