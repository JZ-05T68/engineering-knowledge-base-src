# Engineering Knowledge Base v0.5.0

发布日期：2026-08-17

v0.5.0 是 EKB 第一个正式引入 AI provider 基础设施与 Optional Hybrid Retrieval 的公开版本，
同时继续以本地文件和 SQLite 为唯一事实来源。完整源码与正式发布记录位于
[engineering-knowledge-base-src](https://github.com/JZ-05T68/engineering-knowledge-base-src)。

## Highlights

- Qwen Completion / Embedding / Rerank 职责分离的 provider 契约；
- page-level embedding、SQLite 持久化与 SHA-256 freshness；
- lexical recall、persistent vector recall、RRF Hybrid Retrieval 与关键词 fallback；
- 页面索引编排、批量限制、staging guard 与 cost guard；
- production `data/` / 8501 与 staging `staging-data/` / 8502 隔离；
- 证据对象、来源追溯、人工确认和引用证据包继续保持本地 evidence-first 工作流。

## Local-first boundary

AI 默认 manual，不需要 API Key。未配置可选 AI 时，PDF、搜索、阅读、笔记、证据、文档管理、
删除恢复和备份继续离线工作。production 不自动生成 embedding；原始 PDF 与页面 PNG 不自动
覆盖或删除。应用只绑定 `127.0.0.1`，不包含账号体系和云同步。

## Validation

- Gate 2B：17 / 17 PASS；
- pytest：1399 / 1399 passed；
- Ruff：clean；
- production HTTP health：200；
- SQLite schema v8、integrity ok、foreign key violations = 0；
- 首页与 13 个页面人工验收 PASS；
- frozen 5-query Hybrid benchmark：5 / 5 PASS。

## Known limitations

- 索引粒度是 page-level，不是 chunk-level；
- `qwen3-rerank` 仅有契约和配置，运行时通道尚未接入；
- 真实付费能力需要用户显式配置，离线模式不会获得语义向量增量；
- 5-query benchmark 是最小正向证据，不代表所有工程领域的检索质量；
- Hybrid 不能取代关键词检索、来源核验或人工工程判断。
