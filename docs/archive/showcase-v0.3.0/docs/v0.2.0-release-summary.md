公开发布摘要。v0.2.0 发布时，本仓库仅用于项目介绍与界面演示，完整源码和可安装版本尚未公开。

## 版本定位

超长工程文档与非标准页面处理底座。这是一次本地 PDF 处理底层能力的扩展，不是 AI 版本。

## 核心变化

- **超长工程 PDF 处理底座**：较长工程文档可以完整导入，不缺页、不中断；
- **单页重新处理**：单个页面重新处理时只渲染该页，不再重新渲染整份文档；
- **确定性页面诊断**：空白页、短文本页、横向页和旋转页由明确规则自动识别，同一页面可同时携带多个标志；
- **页级失败隔离**：单页处理失败不会中断后续页面，失败页单独标记并保留错误信息；
- **文档级诊断摘要**：一次导入后给出总页数、成功、失败、空白、短文本、横向、旋转与待复核页的数量及对应页码。

## 验证

- 335 项自动化测试全部通过；
- 建立 120 页真实长文档自动化测试基线；
- 完成 300 页混合 PDF（含横向、旋转、空白、短文本和受控失败页）实际规模验收；
- 人工冒烟测试通过；
- 验收中未发现缺页、假成功、跨页覆盖、数据丢失或文件句柄泄漏。

## 兼容与数据安全

- 没有数据库 schema 迁移；
- 不改变既有页面状态和导入状态语义；
- 单页重新处理不修改非目标页的记录与图片；
- 部分失败的导入不会被错误标记为完全成功。

## 当前边界

- 完整源码与安装包未公开；
- 当前没有 OCR；
- 当前没有 AI 页面识别；
- 不接入 LangChain、LangGraph、Agent 或任何 AI SDK；
- 当前没有断点续传和后台导入；
- 诊断摘要暂不持久化；
- 500 页以上规模未纳入本版本验收。

## 说明

验收环境为 Python 3.11.9 与 PyMuPDF 1.28.0；该环境下 300 页完整处理约 11.7 秒、完整导入约 14.0 秒。性能数字仅代表一次本地验收环境，不构成通用性能承诺。
