# Engineering Knowledge Base v0.4.0

> 历史版本摘要。当前版本与公开范围请以 [v0.5.0 摘要](v0.5.0-release-summary.md) 为准。

## 证据对象与来源模型

v0.4.0 将证据篮从单一文字摘录升级为统一的证据对象与来源模型，让页面依据、
文字摘录和图片局部都能以适合自身的方式长期追溯。

## 当前能力

- **页面证据**：引用整个页面，保留文档、页码与来源定位；
- **文字选区证据**：保存选区内容，并用来源文本哈希识别原文变化；
- **图片区域证据**：以原始页面 PNG 的 SHA-256、像素尺寸和坐标锚定；
- **人工确认**：用户可显式确认或取消确认每条证据；
- **笔记接入**：页面、文字选区和图片区域结构化笔记可由用户加入证据篮；
- **来源返回**：证据保留文档标题、原始文件名、页码、复核状态、项目和标签，
  可回到原始页面核查；
- **侧边栏重排**：按导入、阅读整理、知识组织和维护工作流重新组织；
- **schema v7**：旧证据完整保留并迁移为未确认的文字选区证据。

## 数据与产品边界

- 用户资料继续只存本地，核心能力离线可用；
- 正式服务只监听 `127.0.0.1:8501`；
- 不需要账号、云服务或 API Key；
- 不自动覆盖原始资料，不自动修改用户笔记，不自动删除原始 PDF 或页面图像；
- 本发布不包含 v0.4.1+ 功能。
