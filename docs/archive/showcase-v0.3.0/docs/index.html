本地核心

PDF、页面 PNG、Markdown、SQLite 与 FTS5 保存在用户电脑。正式服务只监听 127.0.0.1:8501。

Evidence-first

整页、文字选区与图片区域都保留文档、文件名、页码、来源哈希和人工确认边界。

Optional AI

默认 manual、无需 API Key。Qwen provider、embedding 与 Hybrid Retrieval 只有在显式配置和操作时介入。
