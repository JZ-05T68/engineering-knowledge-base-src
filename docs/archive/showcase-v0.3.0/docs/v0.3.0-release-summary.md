# Engineering Knowledge Base v0.3.0

> 历史版本摘要。当前版本与公开范围请以 [v0.5.0 摘要](v0.5.0-release-summary.md) 为准。

公开发布摘要。

## 版本定位

v0.3.0 是结构化笔记基础版本，将原有页面级 Markdown 工作流扩展为四类具有明确来源位置的知识对象：

- 文档级笔记；
- 页面级笔记；
- 文字选区笔记；
- 图片区域笔记。

## 核心变化

- 四类结构化笔记使用统一的数据模型、列表和筛选入口；
- 文字选区笔记记录原文位置与来源状态，并支持在确认后重新绑定；
- 图片区域笔记绑定页面图像坐标，并支持来源检查与重新框选；
- 四类笔记都支持由用户明确触发、确认的删除操作；
- 删除导入文档时一致处理关联笔记，同时保留原始资料保护边界；
- SQLite schema 升级到 v5，为结构化笔记提供本地持久化基础。

## 数据安全

- 删除笔记不会删除原始 PDF 或原始页面；
- 删除操作需要用户明确触发与确认；
- 原始 PDF 继续作为最终来源；
- 单个损坏图片被隔离处理，不会导致整页界面崩溃；
- schema v5 迁移前创建并验证备份；
- 用户笔记与来源对象保持分离。

## 当前边界

v0.3.0 不包含：

- LangGraph；
- AI；
- importance；
- 跨文档自动知识关系；
- 自动手写识别；
- 云同步。

完整源码仍在单独的源码仓库中管理。此公开展示仓库只提供项目介绍、界面展示和版本摘要，不提供完整源码或安装包。
