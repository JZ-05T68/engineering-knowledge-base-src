# Engineering Knowledge Base v0.2.1 人工冒烟测试清单

本清单只覆盖 v0.2.1 补丁相关的小范围冒烟验证：版本显示、默认证据篮唯一性、证据操作无回归、
数据与安全边界不变。v0.2.0 既有功能的完整验证仍以 `docs/v0.2.0-manual-test-plan.md` 为准。

## 通用前置条件

- 使用**隔离测试环境**：复制程序到独立目录，使用独立的测试 `data/` 目录或全新空数据目录；
  不得在正式数据库中制造并发实验或写入测试数据。
- 隔离实例使用非正式端口（如 8502–8512），通过
  `streamlit run app.py --server.address 127.0.0.1 --server.port <测试端口>` 启动。
- 正式服务（8501）保持运行，不参与本清单任何步骤。

## 1. 空测试环境启动

- 前置条件：隔离目录、空测试数据目录。
- 操作步骤：启动隔离实例，浏览器打开首页。
- 预期结果：应用正常启动，无报错页面。
- PASS/FAIL 判据：首页可打开且无异常为 PASS，否则 FAIL。

## 2. 版本号显示

- 前置条件：隔离实例已启动。
- 操作步骤：查看首页标题；进入“系统维护”页查看“应用版本”指标。
- 预期结果：首页标题显示“工程知识库 v0.2.1”；系统维护页应用版本显示 v0.2.1。
- PASS/FAIL 判据：两处均显示 v0.2.1 为 PASS；任何一处仍显示 v0.2.0 或其他值为 FAIL。

## 3. 首次访问只创建一个默认证据篮

- 前置条件：空测试数据目录，从未访问过证据篮。
- 操作步骤：首次进入“证据篮”页面；随后在数据库中查询
  `SELECT COUNT(*) FROM evidence_baskets WHERE name = '默认证据篮';`（只读查询）。
- 预期结果：页面显示一个默认证据篮；查询结果为 1。
- PASS/FAIL 判据：篮数量为 1 为 PASS；大于 1 为 FAIL。

## 4. 刷新与多标签页访问后仍只有一个默认篮

- 前置条件：已完成第 3 步。
- 操作步骤：连续刷新“证据篮”页多次；在浏览器多个标签页同时打开“证据篮”和“检索资料”页并
  交替访问；再次执行第 3 步的只读计数查询。
- 预期结果：所有页面显示同一个默认证据篮；计数仍为 1。
- PASS/FAIL 判据：计数为 1 且页面显示一致为 PASS；计数大于 1 为 FAIL。

## 5. 添加证据后跨页面可见同一篮内容

- 前置条件：测试库中已导入至少一份含文本层的 PDF。
- 操作步骤：在“检索资料”页对某一命中页面添加一条证据；切换到“证据篮”页查看；再开一个新
  标签页打开“证据篮”页。
- 预期结果：新证据出现在默认篮中；所有标签页看到同一条证据。
- PASS/FAIL 判据：各处显示一致且证据完整为 PASS；证据丢失或出现在不同篮中为 FAIL。

## 6. 重启后证据仍在

- 前置条件：已完成第 5 步。
- 操作步骤：停止隔离实例，重新启动，进入“证据篮”页。
- 预期结果：默认篮与已添加的证据完整保留。
- PASS/FAIL 判据：证据与篮均在为 PASS；丢失为 FAIL。

## 7. 既有证据操作无回归

- 前置条件：已完成第 5 步。
- 操作步骤：在“证据篮”页调整证据顺序、编辑备注、生成并导出 Markdown 证据包；删除一条证据。
- 预期结果：各项操作成功，导出的证据包内容与实际一致；删除只影响目标条目。
- PASS/FAIL 判据：全部操作符合预期为 PASS；任一操作报错或内容不符为 FAIL。

## 8. 数据库 schema 仍为 v4

- 前置条件：隔离实例已运行过。
- 操作步骤：对测试数据库执行只读查询
  `SELECT MAX(version) FROM schema_migrations;`。
- 预期结果：结果为 4。
- PASS/FAIL 判据：等于 4 为 PASS；其他值为 FAIL。

## 9. 端口、绑定与离线行为不变

- 前置条件：隔离实例运行中。
- 操作步骤：确认正式服务仍监听 127.0.0.1:8501 且健康检查返回 ok；确认隔离实例只绑定
  127.0.0.1；断开网络后刷新隔离实例页面。
- 预期结果：正式服务不受影响；隔离实例不监听 0.0.0.0；离线状态下核心页面正常工作。
- PASS/FAIL 判据：三项均符合为 PASS；任一不符合为 FAIL。
