## Design

- 新增只读工具 `page_visual_search`：一次有界步骤内先用既有词法检索定位页面，
  再把页面 PNG 交给视觉模型读取，返回视觉事实 + 页面稳定引用（回答可回原页）。
- 视觉提示词要求逐字读数、模糊必须承认"看不清"、禁止编造数值。
- 无视觉能力的部署保持原 7 工具面（能力条件注册）；有视觉能力时增加第 8 个工具。
- 决策路由：数值/参数/图表读数类问题 → page_visual_search；描述类 → page_search。
- `QwenProvider.complete_vision`（多模态 completion）+ `AuditedAIProvider.complete_vision`
  （记账：capability=completion，source_feature=page_visual_search 区分）。
- `Settings.ai_vision_model`（默认 qwen3-vl-plus）。
