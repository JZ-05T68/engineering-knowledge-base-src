## Scope

补齐 single-step Agent 的最后一环：

```text
User Request
    ↓
ONE Decision Model Call
    ↓
0 or 1 READ_ONLY Tool
    ↓
ONE Final Answer Model Call MAX
    ↓
existing citation validation
    ↓
structured AgentResponse
    ↓
STOP
```

硬上限：

- Decision model calls <= 1
- Tool calls <= 1
- Final Answer model calls <= 1
- Total model calls per Agent run <= 2
- Agent autonomous retry = 0
- Final Answer retry = 0
- Tool retry by Agent = 0
- JSON repair retry = 0
- Citation repair retry = 0
- Loop = NO
- Multi-step = NO

调用链：

```text
AgentRequest
    ↓
SingleStepAgentService.run()
    ↓
SingleStepAgentExecutor.execute()        # Phase 2A frozen kernel
    ↓
AgentExecutionResult
    ↓
FinalAnswerStage.answer()
    ├─ ANSWER_DIRECTLY → deterministic no-evidence (0 model calls)
    ├─ Tool EMPTY → deterministic no-evidence (0 model calls)
    ├─ Tool FAILED → structured failure (0 model calls)
    └─ Tool SUCCESS / PARTIAL
         ↓
         ToolResultContextMapper
         ↓
         KnowledgeContextPackage
         ↓
         RagAnswerService.answer()       # max 1 completion
         ↓
         existing citation validator
         ↓
         AgentResponse
```

`SingleStepAgentService` 只是 executor + final stage 的薄组合；Phase 2A executor
未被改造成大型 runtime。

## Model Call Budget

- Decision <= 1
- Final Answer <= 1
- Total <= 2
- 任何阶段失败不得重新 decision / Tool / final answer。

## Tool Call Budget

- <= 1（Phase 2A executor 继续强制）
- Final Answer 输出不是 executable decision；模型“还要搜索”不会触发第二 Tool。

## ToolResult Mapping

`ToolResultContextMapper` 规则：

- 只从 `ToolResult.data` + `ToolResult.references` 投影；
- `data.results` 列表与 `references` 按序一一对应（顺序稳定）；
- 单实体 Tool 使用 `data.stable_id` / `data.content` /
  `data.evidence_text` / `data.snippet`；
- provenance / integrity 类无正文数据时使用紧凑结构化摘要；
- 不支持的 stable type（如 `knowledge_source`）跳过；全部跳过 → no-evidence；
- 不发明 stable_id；每个 ContextItem 的 stable_id 来自正式 reference/data；
- 每个 ContextItem 至少带一个 source anchor（来自 reference），以满足
  existing RAG 的 grounded-context 门槛。

## ANSWER_DIRECTLY Semantics

- Decision = ANSWER_DIRECTLY → Tool = 0；
- existing `RagAnswerService` 不支持 zero-context；
- Phase 2C 采用 **minimal zero-context adapter**：确定性 no-evidence 响应，
  Final Answer model calls = 0；
- `grounded = false`，`citations = ()`，`context_stable_ids = ()`；
- 不制造知识库来源。

## SUCCESS / PARTIAL / EMPTY / FAILED Semantics

| ToolResult | Final Answer model calls | Behavior |
|---|---|---|
| SUCCESS | <= 1 | map → RAG answer → citation validation → AgentResponse |
| PARTIAL | <= 1 | same as SUCCESS；Tool warnings 必须保留 |
| EMPTY | 0 | deterministic no-evidence response（`grounded=false`） |
| FAILED | 0 | structured safe failure（不把错误文本交给模型） |

## Citation Lineage

- `ToolResult.references` → mapper → `ContextItem.stable_id` →
  `KnowledgeContextPackage.citations` → model output → existing validator；
- 模型只能引用输入上下文中的 stable_id；
- 不存在的引用 / 混合未知引用 / 缺失引用 → `RagAnswerError` →
  `AgentResponseErrorCode.CITATION_INVALID`；
- 不自动删除坏引用、不自动替换、不调用模型修复。

## Citation Failure Policy

- citation validation failure 后 Final Answer Stage 返回 FAILED；
- 模型调用次数仍为 1（该次调用已发生）；
- repair calls = 0。

## Budget Integration

- 复用 `AiBudgetGuard`（经 `AuditedAIProvider`）；
- Decision 与 Final Answer 共用同一正式 budget boundary；
- Final Answer budget denied → provider transport = 0、Tool 不重试、
  structured `BUDGET_EXCEEDED` failure。

## Audit Integration

- 复用 `AuditedAIProvider`；
- `source_feature="agent_final_answer"`（Phase 2C 新增语义标签，不新增 schema）；
- 成功 / 失败均按既有 `AiCallRecord` 留痕；
- 测试使用 in-memory / temporary audit sink。

## Retry Boundary

- Agent autonomous retry = 0
- Final Answer retry = 0
- Tool retry by Agent = 0
- JSON repair = 0
- Citation repair = 0
- transport retry 沿用既有 QwenProvider 规则；real smoke 使用 0。
