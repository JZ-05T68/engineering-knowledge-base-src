# Engineering Knowledge Base v0.1.2 发布说明

发布日期：2026-07-21

v0.1.2 重点减少大量页面整理时的重复操作，同时把批量写入限定在用户当前看得见、明确确认的范围内。
本版本保持本地优先、单用户、离线可用，正式服务仍只监听 `127.0.0.1:8501`，schema 仍为 v4。

## 当前可见页面批量操作

- 在“检索资料”中，可以选择当前搜索分页里可见的页面并批量修改状态、添加或移除标签、添加或
  移除项目。当前分页最多 10 页。
- 在“待整理页面”中，可以选择数据库当前批次里可见的页面执行同样操作。当前批次最多 20 页；
  较大队列只从数据库加载当前批次。
- 选择不会跨搜索分页或跨待整理批次保留，也不提供“选择全部匹配结果”。切换筛选、排序、分页、
  批次或来源后，旧选择不会在不可见状态下继续生效。
- 添加和移除是独立语义。添加不会替换页面已有的其他标签或项目，移除也只处理明确指定的关系；
  重复添加或重复移除保持幂等。

## 操作前后的安全反馈

- 写入前先显示预检摘要，列出目标数量，以及会修改、保持不变、受保护、缺失或已过期的对象。
- 用户必须明确确认；每次预检产生的一次性操作凭据在执行前即被消费，刷新或重复提交不能再次使用。
- 选中页面在当前会话存在未保存编辑时，相关批量操作会被阻止。另一个浏览器标签页中尚未提交到
  服务端的编辑仍无法被检测。
- 批量写入使用单个数据库事务。受保护、缺失、过期或 SQL 异常不会形成静默部分成功；反馈会明确
  区分成功、未变化、受保护、缺失、过期与回滚。

## 待整理队列性能

待整理页面由原来的全量加载后在界面切片，改为数据库计数加 `LIMIT/OFFSET`，只读取当前批次。
这对当前正式库的 128 页保持轻量，也避免资料库增长后把完整待处理队列无边界加载到内存。

## 本版本未包含

- 跨分页、跨批次选择或选择全部匹配结果。
- 证据篮批量删除、排序或其他批量证据管理。
- 新的连续复核导航闭环。
- 跨浏览器标签页的未保存编辑锁。
- AI、OCR 模型、Embedding、向量数据库、语义检索或外部模型 API。

更多验证范围见 [v0.1.2 人工测试结果](v0.1.2-manual-test-results.md)。
