# Engineering Knowledge Base v0.4.2 发布说明

版本定位：**Prompt Freshness & Stale Output Guard**
（提示词包新鲜度与过期输出保护）

## 本版重点

1. **stale Prompt 自动失效**：证据篮中已生成的引用提示词包与当前问题、当前
   已确认证据的实际 Prompt 输入绑定；有效输入一旦变化，旧结果不再作为当前
   结果显示，并提示重新生成。
2. **真正清除，不复活**：stale 结果从会话状态中真正删除；把问题改回原文、
   反复切换确认状态都不会让旧 Prompt 自动复活。
3. **不过度失效**：不进入 Prompt 的标签、项目、复核状态以及未确认证据的
   信息变化，不会让当前有效 Prompt 失效。
4. **freshness 与生成同源**：fingerprint 直接取当前 `export_prompt_package()`
   输出的 SHA-256，与 Prompt 生成共用同一 confirmed 过滤与 source validation
   路径，无第二套近似逻辑。

## 失效条件（均经真人验证）

问题修改；已确认证据增删；确认状态切换；已确认证据相对排序变化；已确认证据
用户备注变化；整页证据当前页面文本变化；来源校验失效（文本哈希、区域图像
锚点、文档或页面缺失）；清空证据篮。

## 数据与兼容

- 数据库保持 schema v7，本版本无迁移。
- 无新增依赖，无网络请求，无 API Key，不调用任何 AI 服务。

## 已知限制

普通 Markdown 证据包仍为一次生成的静态结果；证据变化后不会自动失效。这是
既有行为，登记为 future candidate，不属于本版本 Prompt freshness 范围。

## 边界

- 继续保持本地优先、单用户、离线可用，正式服务仅监听 `127.0.0.1:8501`。
- 不引入账号、登录、权限、云同步或联网必需功能。
- EKB 不自动调用 AI；AI 仍只是未来可选增强层。
- 不自动覆盖原始资料，不自动修改用户笔记，不自动删除原始 PDF 或页面图像。
- 本发布不包含任何 v0.4.3+ 功能。
