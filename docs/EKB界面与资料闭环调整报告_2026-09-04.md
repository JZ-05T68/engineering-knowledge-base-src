# EKB 界面与资料闭环调整报告

日期：2026-09-04  
检查对象：`127.0.0.1:8501` 正式服  
验证资料：`EKB测试PDF.pdf`

## 一、结论

本轮已经把 EKB 的普通用户主流程收成三步：

1. 添加 PDF、Word 或 PowerPoint 文件。
2. 点击一次“让 Agent 读这份资料”。
3. 用自己的话提问，并从答案打开对应的原始页。

预置 ABC 问题和假答案入口已经从普通用户界面移除。正式服已用固定测试 PDF 实际完成上传、QW3.8 逐页阅读、检索、回答、页码引用、打开原页和手动保存对话。

界面的整体布局、颜色、卡片样式和展示风格没有重做；本轮只调整了入口、功能层级和文字。

## 二、判断依据

方向文档强调：EKB 的价值不是再做一个“上传 PDF 然后聊天”的工具，而是帮助用户长期调用自己过去的资料、经验、方法和判断。RAG 应作为底层能力，不应成为普通用户需要理解的产品概念。

因此，普通用户首先需要看到的是“添加资料、让 Agent 读、提问、查看原页、保存有用对话”，而不是系统内部的资料组织名词和开发维护入口。

## 三、侧边栏调整

### 普通用户现在直接看到

| 现在的名称 | 用途 |
| --- | --- |
| 首页 | 看最近资料和最简单的使用步骤 |
| 问问 Agent | 对已经读完的资料提问 |
| 添加资料 | 上传文件并一键让 Agent 阅读 |
| 我的资料 | 看原始页面、人工修改识别文字 |
| 查看识别结果 | 对照原始页面查看 AI 识别的文字；不是必做步骤 |
| 我保存过的内容 | 查看由用户亲手保存的对话 |

“更多”中只保留“管理资料、备份与修复、使用帮助”。这些功能有用，但不是第一次使用 EKB 时必须理解的内容。

### 从主侧边栏移除或隐藏的内容

| 原名称 | 处理方式 | 原因 |
| --- | --- | --- |
| 检索资料 | 从主侧边栏移除 | 首页已有搜索，Agent 也会自动查找资料，重复入口会让用户困惑 |
| 导入记录 | 隐藏 | 属于过程记录，不是普通用户的主要目标 |
| 结构化笔记 | 隐藏 | 名称抽象；人工改字已放进“我的资料”页 |
| 证据篮 | 隐藏，内部仍保留 | “证据篮”不是日常用语；普通用户只需要看“答案出处” |
| 知识对象 | 隐藏，内部仍保留 | 属于系统内部资料模型，初次使用无需理解 |
| 知识聚合 | 隐藏，内部仍保留 | 属于底层组织方式，不应要求用户先学习概念 |
| 标签管理 | 隐藏 | 资料较少时没有必要；以后可放入高级管理 |
| 项目管理 | 隐藏 | 与首次添加和提问无关；以后可放入高级管理 |
| 文档管理 | 改为“管理资料”，放进“更多” | 名称更直接，也避免与“浏览资料”形成重复入口 |
| AI 调用台账 | 隐藏 | 是开发者诊断信息，普通用户不需要看到 |
| 系统维护 | 改为“备份与修复”，放进“更多” | 直接说明用户能在这里做什么 |
| 运行说明 | 改为“使用帮助”，放进“更多” | “使用帮助”更符合普通用户的理解方式 |
| 组织与管理 | 改为“更多” | 原名称范围太大，容易让用户误以为使用前必须配置 |

旧的高级页面没有直接删除文件和数据，避免破坏已有功能或旧链接；它们不再出现在普通用户主路径中。

## 四、文字调整原则

| 原表达 | 新表达 |
| --- | --- |
| 工作台 | 首页 |
| 知识 Agent | 问问 Agent |
| 导入资料 | 添加资料 |
| 浏览资料 | 我的资料 |
| 待整理页面 | 查看识别结果 |
| 知识记忆、长期记忆 | 我保存过的内容 |
| 引用来源 | 依据 |
| 有依据回答 | 已在资料中找到 |
| 来源完整性、来源元数据 | 不再向普通用户显示 |
| 页面整理稿（Markdown） | 修改这一页的文字 |
| OCR、embedding、chunk、索引、RAG | 不在普通处理界面显示 |

“查看识别结果”页明确提示：“AI 已自动识别。只有发现文字错误时才需要修改。”，避免让用户误以为必须逐页人工检查。

“我保存过的内容”页只显示保存日期、讨论名称、内容预览以及“查看 / 删除”操作。类型、状态、内部编号和来源关系等高级元数据仍保留在数据库中，但不在普通页面展示。

## 五、已实现的完整链路

### 1. 添加文档

- 支持 PDF、DOC、DOCX、PPT、PPTX。
- Word 和 PowerPoint 在本机通过已安装的 Microsoft Office 转成逐页 PDF 后，进入同一套页面处理流程。
- 原始 Office 文件会单独保留，不会被转换结果覆盖。
- 每一页保留原始页码、页面图片和原始提取文字。

### 2. 让 Agent 阅读

- 用户只点击“让 Agent 读这份资料”。
- 处理中只显示“正在读取 X / Y 页”。
- 普通文字页直接使用原文字层；图片页或手写页会尝试文字识别。
- 随后逐页调用 QW3.8，生成页面摘要、关键词和关键事实作为辅助信息。
- AI 摘要不会替代原文；回答检索仍使用原始页面文字和用户人工修改内容。
- 所有页面成功后才显示“资料已经读完，可以去问 Agent 了”，并直接提供“去问 Agent”按钮。

### 3. 人工修改

- “我的资料”页只保留原图、上一页/下一页、页码和文字修改。
- 用户修改后点击“保存修改并让 Agent 重读”。
- 原始提取文字继续保留；人工修改单独标记。
- 如两者冲突，QW3.8 被明确要求以人工校对内容为准，同时仍引用原始文件页码。

### 4. Agent 搜索和回答

- 普通用户界面不再提供预置 ABC 问题或假答案模式。
- Agent 只检索已经完成逐页阅读、且文字没有过期的页面。
- QW3.8 根据找到的原文回答；资料不足时必须明确说没有找到，不能编造。
- 答案显示资料名称和原始页码。
- “依据”紧跟答案展示，第一条依据默认展开；点击“查看原文”可直接回到对应页原图和人工修改区。

### 5. 保存有用的问答

- 每个成功回答下方增加“保存这次问答”。
- 只有用户亲手点击才会保存，不会自动加入“我保存过的内容”。
- 保存内容只包含当前用户问题和当前一次 Agent 回答，并尽量关联第一条原始文档页面。
- 保存后可在“我保存过的内容”中再次查看，但不会自动改变以后的普通资料回答。

## 六、正式服端到端验证

固定测试 PDF 共 10 页。正式服实际显示了“正在读取 2 / 10 页”“正在读取 7 / 10 页”，最后显示“已读完 10 / 10 页”和“Agent 已读完，现在可以提问”。

提问：

> 这份资料里的唯一验证标记是什么？

正式服回答：

> EKB-VERIFY-9F27K

页面同时显示：

- 《EKB测试PDF》第 8 页；
- “查看原文”按钮，依据中明确显示第 8 页；
- 打开后页码选择器为“第 8 页”，并显示该页原图；
- “保存这次问答”点击后显示“这次问答已保存”。

完整自动验证还覆盖：第 2 页 1379 rpm、第 5 页 42 分钟、第 6 页 E17、第 7 页每 500 小时，以及资料中不存在的轴承型号问题不编造。

## 七、当前限制与后续建议

1. Word 和 PowerPoint 的本机分页转换依赖这台电脑已安装 Microsoft Word / PowerPoint；本轮已经用提供的 Word 文件实际转换并导入为 8 页。
2. 手写识别效果取决于字迹和图片清晰度，因此保留人工修改是必要的；不能承诺任何手写内容都能一次识别正确。
3. 旧的高级管理页仍保留专业词汇，但已退出普通用户主路径。后续如继续精简，可统一改写这些隐藏页面，不需要再改变新版首页的颜色和布局。
4. 建议后续视频继续使用同一份 `EKB测试PDF.pdf`，问题顺序保持固定，便于每次版本复核。

## 八、首次使用与回答层级复核（2026-09-05）

### 空库首页

- 当资料数量为 0 时，不再显示搜索框、宣传区、统计卡片、最近资料和“问问 Agent”主按钮。
- 首屏标题直接显示“第 1 步：添加资料”。
- 首屏只说明三步：“添加资料 → 让 Agent 阅读 → 开始提问”。
- 唯一主操作是“添加资料”，页脚继续保留 EKB v0.6.0。
- 已增加自动化测试，确认空库首屏没有搜索框和系统统计概念。

### 添加资料

- 上传后仍只有一个处理主按钮：“让 Agent 读这份资料”。
- Word / PowerPoint 转换阶段只显示“正在准备资料”，不显示转换器、解析或索引术语。
- “正在读取 X / Y 页”现在只由 QW3.8 的逐页阅读进度驱动，不再在文件导入和文字识别阶段重复从第 1 页计数。
- 完成后显示“资料已经读完，可以去问 Agent 了”，并直接提供“去问 Agent”。
- “查看识别结果（可选）”明确表示人工核对不是必做流程。

### Agent 回答

- 页面顺序固定为“答案 → 依据 → 查看原文 → 保存”。
- 删除了答案区域下方重复出现的一组来源按钮，只保留一套依据列表。
- 第一条依据自动选中，让“查看原文”无需先寻找来源入口。
- 保存区移动到全部依据之后，并增加分隔线和“觉得这次对话以后还会有用？”提示。
- “保存这次问答”保持普通按钮样式，不与来源核验争夺主视觉焦点。
- 模型回答中的 Markdown 粗体符号和列表星号会转换为普通页面文字，不再把 `**`、`*` 暴露给用户。
