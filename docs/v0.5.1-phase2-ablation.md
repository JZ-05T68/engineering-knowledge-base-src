## 三、单项结论

1. **A1（资格门）是单键收益最大的旋钮**：MRR +0.066，regression 7→5，
   同时消除 F 类语义召回暴露（D-02）并压缩结果数（D-03，median 25→9）。
   它直接命中 D-01 机制环①「零语义证据也拿 vector rank」。
2. **B（top-k）单独不够**：零相似页会填满 cap（A4 的 21 个 sim=0 候选截到 K 仍是零证据页），
   regression 只减 1；但它把结果数严格有界化，是 D-03 的直接手段，且 B3/B5/B10 差异不大
   （对 K 不敏感，K=5 取中而非「方便通过」）。
3. **C1-w0.25 有害**：稀释了 H2 的多页语义收益（imp 2→1），唯一全局变差的变体。
   权重不宜激进。
4. **C2（lexical 优先 tie-break）精确修复 J1**，与 Phase 1D 机制环③的预测一致
   （平分 1/61 时不再由 page_id 决胜）。
5. **C3 与 C1-w0.5 等效于本语料**（均 reg→5），但不能消除 F 暴露与结果数膨胀
   （零证据页仍占 top-5 槽位）。
6. **没有任何旋钮能修 C3-query**（相关页 power/p6 未嵌入，对手页有真实 topic 重叠）：
   全变体 unchanged。该 regression 只能靠提高 embedding 覆盖率解决——
   这是「覆盖率」问题而非「融合算法」问题，诚实记录。

## 四、候选策略（提交人工确认）

**D2 组合 = 资格门（sim > 0）+ vector 候选池 top_k=5 + RRF vector 权重 0.5**

- regression 7→2（A4/B4/E1/I2/J1 fixed，J2 improved-not-fixed，C3-query unchanged）；
- 语义收益全部保留（C2/H2/D3 preserved，跨文档覆盖 D1–D3 全 True）；
- Hybrid 三项聚合指标追平 Keyword（MRR 0.9183 = keyword），不再整体劣化；
- 结果数 21/25/34 → 3/9/29（vector-side 膨胀显著缓解，见下 D-03 边界）；
- F 类语义召回 Top5 暴露在 fixture 下消除（D-02 见第五节双层状态）。

**保留意见（必须随策略一起记录）**：

1. fixture 的 `sim > 0` 门在真实模型上可能近似无操作——真实 embedding 相似度几乎恒为正。
   资格门的**真实形态**（绝对阈值 / 相对最佳值比例 / top-k 内正证据即可）必须用真实
   Qwen 相似度分布校准，**不得**从 fake evidence 冻结绝对 cosine 阈值。
2. top_k=5 与 weight=0.5 在 fixture 上不敏感（B 系平坦、w=0.25 才有害），
   但真实模型下应复核。
3. C3-query 型 regression 的唯一解是覆盖率，提示「索引覆盖率」应作为
   Retrieval Stability 维度的长期指标。

## 五、D-02 处置状态（双层）

**Production status: OPEN**

- 现行生产代码不存在 weak/no-answer product boundary：弱正证据页（sim 低但 > 阈值）
  仍会以「语义召回」出现在结果中，没有 honest weak-evidence 提示。
- 因此当前产品**不能**声称「知识库中没有答案」或「以下仅为弱相似页面」。

**Experimental disposition: PARTIALLY MITIGATED BY D2 CANDIDATE**

- fixture 下：含资格门的变体（A1/D1/D2）完全消除 F2/F3 的语义召回 Top5 暴露。
- 该改善发生于**尚未落地的 fixture ablation**，不是 production 行为，故不得
  计为 production 已缓解。
- 待 Phase 3 决定：最小产品边界提案（当 keyword 零命中且 hybrid 结果全部/主要为
  vector-only 时，结果区显示诚实提示，如「关键词未命中，以下仅为语义相似页面，
  相关性请自行判断」），不把弱 vector Top5 包装成普通成功语义召回。
  该提案不需要 LLM / rerank / 第二次 AI 调用。
