## 6. 遗留债务登记（CONDITIONAL GO 条件）

### OBS-E Live Selection Rectangle — MEDIUM，DEFER WITH EXPLICIT DEBT（杨洋裁决）

- **状态**：known deferred debt，**不是 FIXED**。v0.4.3 发布不改变其状态。
- **Root cause**：`streamlit-image-coordinates` 0.4.0 前端缺少 drag-move 事件与 live overlay 结构，拖拽中无即时矩形反馈（详见 design freeze §15 OBS-E）。
- **Impact**：图片区域框选拖拽过程中看不到正在形成的选区，松开鼠标后才显示。
- **Workaround**：mouseup 后立即显示区域坐标 caption 与红框覆盖预览（`_render_region_overlay`），保存前可检查，可「清除框选」后重选。
- **Why non-blocking**：操作可完成；保存前可检查、可修正；original-pixel anchor 正确性由既有自动化钉住；不破坏 grounding integrity / source traceability / data safety。
- **Target**：v0.5.x candidate（届时统一评估 vendored fork 与组件替换方案）。
- **未来实现硬契约（冻结）**：不得回退 FIX-A responsive complete-display 行为；任意合理窗口宽度下不得出现图像裁剪；不得引入组件内部横向滚动条；不得改变 original-pixel anchor semantics；不得仅为 live preview 引入未经论证的第三方前端依赖。
