# Engineering Knowledge Base v0.4.0 发布说明

版本定位：**Evidence Objects & Source Model**
（证据对象与来源模型）

## 本版重点

1. **统一证据对象**：证据篮支持整页、文字选区与图片区域三类证据。
2. **可校验来源模型**：不同证据类型采用与其语义匹配的来源锚点与失效检查。
3. **人工确认状态**：每条证据均可由用户显式确认或取消确认。
4. **笔记与证据工作流接入**：结构化笔记可在用户操作下加入证据篮。
5. **侧边栏信息架构重排**：页面顺序与内部导航按完整工作流重新组织。

## 证据对象与来源模型

- **页面证据**引用整个页面，保存文档、页码、来源定位与采集时文本哈希；页面文本
  后续编辑不改变整页引用语义。
- **文字选区证据**保存选区内容及来源文本哈希；来源原文变化时要求重新核对。
- **图片区域证据**保存原始页面 PNG 的 SHA-256、像素尺寸和归一化矩形坐标；
  图像变化或坐标越界时来源锚点失效。
- 三类证据统一保留文档标题、原始文件名、页码、复核状态、项目、标签、来源定位、
  用户备注和加入顺序，可从证据篮返回原始页面核查。

## 人工确认与 UI

- 证据对象新增 `unconfirmed` / `confirmed` 状态；确认时记录时间，取消确认时清除。
- 证据篮按类型显示文字选区、整页引用或图片区域坐标，并提供显式确认操作。
- 浏览页可将当前整页或文字选区加入证据篮；图片区域笔记创建后可显式加入证据篮。
- 结构化笔记列表提供与笔记类型匹配的加入入口；重复证据由数据库约束与服务层
  提示共同阻止。
- 侧边栏顺序调整为：导入资料、导入记录、浏览资料、检索资料、待整理页面、
  结构化笔记、证据篮、知识聚合、标签管理、项目管理、文档管理、系统维护、
  运行说明。

## 数据与迁移

- 数据库从 schema v6 升级为 schema v7。
- `evidence_items` 增加证据类型、图片区域锚点、人工确认状态和确认时间字段，并以
  create-copy-drop-rename 方式在单事务中重建。
- 既有证据的 id、数量与内容保持不变，映射为 `text_selection` + `unconfirmed`；
  迁移前沿用既有自动备份机制，核心文档、页面和 FTS 数据保持不变。

## 边界

- 继续保持本地优先、单用户、离线可用，正式服务仅监听 `127.0.0.1:8501`。
- 不引入账号、登录、权限、云同步或联网必需功能。
- 不要求 API Key；AI 仍只是未来可选增强层。
- 不自动覆盖原始资料，不自动修改用户笔记，不自动删除原始 PDF 或页面图像。
- 本发布不宣称任何 v0.4.1+ 功能。
